# 결과물 형태에 "/skill" 항목 추가

## 변경 내용
활동기록 03 최종 결과물 단계의 [결과물 형태] 선택지에 `/skill` 옵션을 하나 추가합니다.

선택지 목록: 웹앱 · 모바일앱 · 챗봇·AI 도구 · 자동화 도구 · 수업자료·콘텐츠 · **/skill**

## 기술 상세
- `src/lib/record-schema.ts`의 `OUTPUT_TYPES` 배열 끝에 `"/skill"` 추가.
- `RecordEditor`, README 출력, 사례집 문서는 모두 이 배열을 참조하므로 추가 수정 불필요.
- 기존에 저장된 값은 문자열로 보관되므로 영향 없음.

## 가이드
사용자 가이드(/guide)의 활동기록 설명에 결과물 형태 선택지 목록이 명시되어 있으면 `/skill`을 함께 반영합니다.

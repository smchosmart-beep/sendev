## 목표
모바일에서 좁은 셀에 일정 제목이 한 글자로 잘려 보이는 문제를 해결합니다. 모바일에서는 (1) 달력 셀에 점 마커만 표시하고 날짜를 탭하면 하단에 그날 일정 목록을 보여주는 "달력 보기"와, (2) 해당 월 전체 일정을 날짜순 목록으로 보여주는 "목록 보기"를 토글로 전환할 수 있게 합니다. 데스크톱은 기존 그리드(제목 표시) 유지.

## 변경 대상
- `src/routes/_main.calendar.tsx`

## 변경 내용
1. 상태 추가
   - `mobileView: "calendar" | "list"` (기본 "calendar")
   - `selectedDay: string | null` (탭한 날짜 ISO)
2. 헤더 영역에 모바일 전용 보기 전환 토글 버튼 추가 (`sm:hidden`): 달력/목록 아이콘 토글
3. 달력 그리드
   - 모바일에서 셀 안 이벤트는 제목 대신 점 마커(최대 3개 + N개 표시)로 표시
   - `sm` 이상에서는 기존처럼 제목 텍스트 표시
   - 셀을 버튼으로 만들어 탭하면 `selectedDay` 설정
   - 선택된 날짜 셀 시각 강조
4. 모바일 "달력 보기" 하단에 선택된 날짜(`selectedDay`, 기본은 오늘)의 일정 목록 섹션 추가 — 제목/시간/장소 요약, 탭 시 기존 상세 Dialog 열림. 일정 없으면 안내 문구
5. 모바일 "목록 보기"는 그리드 대신 해당 월 전체 일정을 날짜 오름차순으로 카드 리스트 렌더, 각 항목 탭 시 상세 Dialog
6. 기존 상세 Dialog/공휴일/오늘 강조 로직 재사용

## 검증
- 모바일(약 390px)에서 점 마커 표시, 날짜 탭 → 하단 목록, 달력/목록 토글 동작 확인
- 데스크톱에서 기존 그리드(제목 표시) 변화 없는지 확인

# 모바일 게시판 헤더·배지 표시 개선

스크린샷에서 확인한 문제 2가지:
1. "이 게시판 읽음 처리" 버튼 라벨이 길어 게시판명("홈커밍데이")이 두 줄로 밀림.
2. 작성자 배지가 3개 모두 펼쳐져(expand) 카드가 지저분하고 세로로 길어짐.

## 변경 내용

### 1. 읽음 처리 버튼 모바일 축소

- `src/components/MarkAllReadButton.tsx`
  - 라벨 영역을 `hidden sm:inline`으로 감싸 모바일에서는 아이콘(CheckCheck) + 읽지 않은 수 배지만 표시.
  - `aria-label`에 기존 라벨을 유지해 접근성 확보.
  - 데스크톱(sm 이상)은 현재와 동일하게 "이 게시판 읽음 처리" 전체 라벨 표시.
- `src/routes/_main.board.$slug.index.tsx` (290-310행)
  - 헤더 행에 `gap-2` 명시, 게시판명 `h2`에 `min-w-0` + 제목 span에 `whitespace-nowrap`을 주어 버튼과 무관하게 한 줄 유지.
  - 버튼 영역 컨테이너에 `shrink-0` 추가.

### 2. 카드 배지: 모바일은 접힘, 데스크톱만 전체 펼침

- `src/components/AuthorBadge.tsx`
  - `expand` prop에 반응형 옵션 추가는 하지 않고, 호출부에서 두 가지를 조건부 렌더하는 방식 대신 `expand`일 때도 클래스로 제어할 수 있게 함 — 가장 단순한 방식: 호출부에서 아래처럼 두 개 렌더.
- `src/components/PostListCard.tsx` (59-64행)
  - 배지 영역을 두 개로 분리:
    - 모바일(`sm:hidden`): `only="awards"` (expand 없음) → 대표 배지 1개 + `+N` 칩, 탭하면 팝오버로 전체 확인(기존 동작 재사용).
    - 데스크톱(`hidden sm:inline-flex`): 현재처럼 `only="awards" expand`로 전체 펼침 유지.

## 영향 범위

- 순수 마크업/CSS 변경. 서버·DB·데이터 로직 변화 없음.
- 데스크톱 화면은 시각적으로 현재와 동일.
- `AuthorBadge`의 기존 팝오버 동작을 모바일에서 재사용하므로 정보 접근성 손실 없음.

## 가이드

- 가이드의 목록 카드 설명 중 배지 표시 관련 문구가 있으면 "모바일에서는 대표 배지 + +N으로 표시"로 갱신.

## 검증

- 모바일 폭(375px)에서 게시판명이 한 줄로 유지되는지 확인.
- 모바일에서 읽음 처리 버튼이 아이콘+숫자만으로 표시되고 동작하는지 확인.
- 배지 3개 작성자 카드에서 모바일은 대표 배지 + +2, 탭 시 팝오버 노출 확인.
- 데스크톱에서 기존 레이아웃(전체 배지 펼침, 전체 라벨) 유지 확인.

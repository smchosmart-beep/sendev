# 02 문제 정의 과정 - 22일 회의 탭 정리

## 1. 추가 버튼 정리
현재 "문제 정의 과정 기록" 섹션 아래에는 `+ 문제 정의 기록 추가` 버튼 하나가 있고, 새 기록을 만들면 탭이 비어 있는 상태로 생성됩니다.

- 이 버튼을 `+ 그 밖의 문제 정의 메모 추가` 하나로 바꾸고, 새 기록은 탭이 [그 밖의 문제 정의 메모]로 지정된 채 생성되도록 합니다.
- 다른 탭(22일 회의 / 인터뷰 기록 / 인터뷰 후 회의)이 필요하면 만들어진 기록에서 탭을 눌러 바꾸면 됩니다(기존 동작 그대로).

## 2. 첨부 이미지를 크게 보기
[22일 팀빌딩·문제 정의 회의] 탭의 페르소나 이미지·고객 여정 맵 이미지는 지금 작은 썸네일(가로 약 112px)로만 보입니다.

- 작성 화면: 저장된 이미지를 게시판 본문처럼 넓은 폭(칸 전체 너비, 최대 높이 제한 안에서 원본 비율 유지)으로 세로 배치해 표시. 이미지 클릭 시 원본 새 창 열기. 삭제(X) 버튼은 그대로 유지.
- README 출력: 파일명 링크 대신 실제 이미지가 삽입되도록 마크다운 이미지 문법으로 출력(이미지 확장자일 때만, 그 외 파일은 지금처럼 파일명 링크).
- 사례집 PDF: 해당 열의 이미지를 카드 안에 큰 이미지로 렌더링(인쇄 시 잘리지 않게 폭 100%·높이 상한 적용).

## 3. 유튜브 링크 하이퍼링크
- 저장된 종이 프로토타입 링크가 작성 화면에서도 클릭 가능한 링크로 보이도록, 입력칸 아래(또는 옆)에 "링크 열기" 형태의 하이퍼링크를 표시합니다. `https://` 없이 입력해도 자동 보정해 연결합니다.
- README·사례집 출력은 이미 링크 처리가 되어 있으므로 동일 보정만 확인합니다.

## 기술 메모
- `src/components/RecordEditor.tsx`: RowSection의 addLabel/기본 subtype 처리, RowItem의 이미지 미리보기 스타일과 링크 열기 UI.
- `src/lib/record-schema.ts`: process 섹션 addLabel 문구 및 기본 subtype 상수.
- `src/lib/record-readme.ts`, `src/components/record/CasebookDocument.tsx`: imageCols 열은 이미지로 출력.
- 데이터 구조(DB) 변경 없음, 서버 호출 추가 없음.

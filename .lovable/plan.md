## 목표
관리자 페이지에서 같은 카테고리(탭) 안에 속한 게시판(예: 해커톤의 입문형·성장형·도전형) 순서를 위/아래로 옮겨 변경할 수 있게 합니다.

## 배경
- 게시판 데이터는 `categories` 테이블에 저장되고 `sort_order` 컬럼으로 정렬됩니다. 목록(`listCategories`)도 이미 `sort_order` 오름차순으로 불러옵니다.
- 즉 데이터 구조는 그대로 두고, 두 게시판의 `sort_order` 값을 맞바꾸는 기능과 관리자 UI 버튼만 추가하면 됩니다. (히어로 슬라이드의 순서 변경 기능과 동일한 방식)

## 구현 내용

### 1) 서버 함수 추가 (`src/lib/platform.functions.ts`)
- 기존 `swapHeroSlideOrder`와 동일한 방식으로 `swapCategoryOrder` 서버 함수를 추가.
- 입력: 옮길 게시판 id, 자리를 바꿀 이웃 게시판 otherId.
- 두 행의 `sort_order` 값을 서로 교환.

### 2) 조회 옵션 (`src/lib/platform.queries.ts`)
- 별도 추가 불필요(기존 `categoriesQueryOptions` 재사용, 변경 후 `["categories"]` 무효화).

### 3) 관리자 UI (`src/routes/admin.categories.tsx`)
- 카테고리 목록 필터가 **특정 탭(예: 해커톤)으로 선택되어 있을 때만** 순서 변경 버튼(▲/▼)을 노출.
- "전체" 필터일 때는 순서 변경 버튼을 숨겨서 사용자 혼란을 방지.
- 순서 이동은 같은 탭(tab_group) 안에서만 적용:
  - 같은 탭에 속한 게시판들을 `sort_order` 순으로 추려, 현재 게시판의 바로 위/아래 이웃과 swap.
  - 그룹에서 맨 위 항목의 "위로", 맨 아래 항목의 "아래로" 버튼은 비활성화.
- 버튼 클릭 시 `swapCategoryOrder` 호출 → 성공하면 `["categories"]` 쿼리 무효화하여 목록 갱신, 토스트 표시.

## 사용자 화면 동작
- 관리자 → 카테고리 관리 목록 → 탭 필터(예: 해커톤) 선택 → 각 게시판 옆 ▲/▼ 버튼으로 순서 조정.
- 변경된 순서는 카테고리 목록 페이지(`/board`)와 사용자 화면 전반에 즉시 반영됩니다.

### 문제
모바일 후기 포스트잇 띠를 펼쳤을 때, 포스트잇 카드 아래에 빈 공간이 생겨 카드 영역이 화면 맨 아래까지 닿지 않음. 펼침 컨테이너의 `max-h-60`(240px)이 실제 카드 높이(`w-44 aspect-square` ≈ 176px)보다 커서 하단 여백이 발생.

### 수정 (`src/components/HackathonReviews.tsx`)
`HackathonReviewStripMobile`의 펼침 컨테이너에서:
- `max-h-60 pb-3` → 카드 높이에 맞는 값으로 조정하여 아래 빈 공간 제거
  - 펼침 상태 클래스를 `max-h-60 pb-3 opacity-100` → `max-h-52 pb-2 opacity-100` 정도로 줄여 카드 바로 아래까지만 영역이 차지하도록 함
- 필요 시 카드 래퍼/패딩을 미세 조정하여 카드 하단이 화면 맨 아래(`bottom-0`)에 맞닿도록 함

### 검증
- 모바일 뷰포트(약 384px)에서 펼친 상태 스크린샷으로 카드 아래 빈 공간이 사라지고 화면 하단까지 닿는지 확인

### 영향 범위
- 모바일 후기 포스트잇 띠의 펼침 높이/여백만 변경. 동작·데이터 변화 없음

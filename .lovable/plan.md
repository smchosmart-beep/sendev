## 목표

게시글/공지 작성 화면에서 마크다운 원본(특히 길고 지저분한 이미지 서명 URL)이 그대로 노출되는 문제를 해결합니다. 작성 중에도 **이미지는 실제 미리보기**로, **링크는 제목 텍스트만** 보이는 리치 에디터로 바꿉니다.

## 접근 방식

저장 형식은 지금처럼 **마크다운 그대로 유지**합니다. 화면 표시(게시글 상세 페이지의 `ReactMarkdown` 렌더링)는 전혀 바꾸지 않습니다. 오직 **편집 화면**만 리치 에디터로 교체합니다.

이를 위해 TipTap 에디터에 마크다운 입출력 기능을 붙여, 에디터에 들어올 때 마크다운 → 보기 좋은 형태로 변환하고, 저장할 때 다시 마크다운으로 변환합니다. 덕분에 기존에 작성된 글들도 그대로 호환됩니다.

## 변경 사항

### 1. 패키지 추가
- `@tiptap/react`, `@tiptap/starter-kit`, `@tiptap/extension-image`, `@tiptap/extension-link`, `tiptap-markdown`

### 2. `src/components/PostEditor.tsx` (재작성)
- 기존 `<textarea>` 대신 TipTap 기반 리치 에디터로 교체
- 상단 툴바는 지금과 동일하게 유지: 제목·굵게·기울임·인용·목록·번호목록·링크·이미지
- **이미지**: 지금처럼 기기에서 사진을 골라 `post-images` 버킷에 업로드 → 받은 URL을 에디터에 **실제 이미지로 삽입** (긴 URL은 화면에 안 보임)
- **링크**: 지금의 "링크 삽입" 모달(제목 + URL) 유지 → 본문에는 **제목 텍스트만** 파란 링크로 표시, URL은 숨김
- `value`(마크다운)를 받아 에디터에 표시하고, 편집 시 마크다운으로 직렬화해 `onChange`로 전달 → 저장 데이터 형식 변화 없음
- 인터페이스(`value`, `onChange`, `placeholder`, `rows`, `className`)는 그대로 유지 → 사용처(`admin.notices.tsx`, 게시글 작성/수정) 수정 불필요

### 3. 표시(렌더링)는 무변경
- 게시글 상세 페이지의 `ReactMarkdown` 렌더링, 링크 새 탭 열기 등 기존 동작 그대로 유지

## 기술 메모

- 저장 포맷이 마크다운으로 유지되므로 기존 글/공지와 100% 호환됩니다.
- 이미지 업로드 로직(서명 URL 생성, 5MB 제한, 이미지 타입 검증)은 그대로 재사용합니다.
- 에디터 스타일은 디자인 토큰(`src/styles.css`)에 맞춰 적용합니다.

# 사례집 합본 인쇄 — 표지 항상 새 페이지 시작

## 배경

관리자 대시보드(활동기록 현황)에서 사례집 합본을 인쇄하면, 앞 팀 문서의 마지막 페이지 뒤에 다음 팀 표지가 같은 페이지에 이어서 붙습니다. 여백 축소 작업(연속 흐름 조판)에서 `break-after: auto`로 바꾸면서 표지 구분이 사라진 것이 원인입니다. 표지는 프로젝트를 구분하는 역할이므로 항상 새 페이지에서 시작해야 합니다.

## 변경 내용

`src/styles.css`의 인쇄 전용(`@media print`) 사례집 블록만 수정합니다.

- `.casebook-cover`에 `break-before: page` 추가 → 각 팀 표지가 항상 새 쪽에서 시작
- 단, 첫 번째 문서의 표지에는 빈 페이지가 생기지 않도록 예외 처리:
  - `.casebook-doc:first-of-type .casebook-cover { break-before: auto; }`
  - (합본 컨테이너 안에서 각 팀 문서는 `article.casebook-doc` 형제 요소이므로 `:first-of-type`이 첫 팀만 가리킴)

## 영향 범위

- 인쇄(`@media print`) 스타일만 변경하므로 화면 미리보기에는 영향 없음
- 단일 팀 사례집 출력(08 사례집 출력)은 문서가 1개라 첫 표지 예외 규칙이 적용되어 기존과 동일하게 동작
- 데이터 구조·서버 함수·다른 인쇄(README) 스타일은 변경하지 않음
- 표지 내용(폰트 크기, 팀원 표시 등 기존 개선 사항)은 그대로 유지

## 검증

- 타입 검사 통과 확인
- 관리자 합본 인쇄 미리보기에서 2번째 팀 표지가 새 페이지에서 시작되는지 확인

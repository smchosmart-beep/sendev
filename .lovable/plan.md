# 닉네임 입력 시 내 평가 여부 자동 확인

평가자 닉네임은 화면에 노출되지 않기 때문에, 본인이 이미 평가했는지 알 수 없는 문제가 있습니다. 평가 폼에 닉네임을 입력하면, 입력이 멈춘 직후 서버에서 같은 닉네임의 기존 평가가 있는지 자동으로 확인해 안내합니다. (이전 점수는 폼에 채우지 않습니다.)

> 닉네임은 중복 평가 방지용이므로 흔하지 않은 것으로 정해주세요. 같은 닉네임으로 다시 제출하면 점수가 갱신됩니다.

## 동작

- 닉네임 입력칸에 닉네임을 입력하면(타이핑이 잠시 멈추면) 자동으로 조회
- **이미 평가한 경우**: "이미 평가하셨어요 (○월 ○일 제출)" 안내만 표시. 별점은 비워둠. 점수를 새로 매겨 다시 제출하면 갱신됨. 제출 버튼은 "평가 수정"으로 표시
- **아직 평가하지 않은 경우**: "아직 평가하지 않으셨어요" 안내 표시, 빈 폼 유지. 제출 버튼은 "평가 제출"로 표시
- 다른 사람의 닉네임·점수는 절대 보이지 않음 (입력한 본인 닉네임과 정확히 일치하는 것만 조회)

```text
[ 닉네임: 홍길동              ]
 ✅ 이미 평가하셨어요 · 6월 2일 제출 (점수를 새로 매겨 다시 제출하면 갱신돼요)

 항목별 별점 ... (비어 있음)

 [ 평가 수정 ]
```

## 변경 사항

### 1. 서버 함수 (`src/lib/platform.functions.ts`)
- 새 서버 함수 `getMyReview` 추가
  - 입력: `postId`, `reviewerName`
  - 동작: 해당 게시물에서 입력한 닉네임과 정확히 일치하는 평가 1건만 조회
  - 반환: 있으면 `{ found: true, createdAt }`, 없으면 `{ found: false }` (점수는 반환하지 않음)
  - 본인 닉네임과 일치하는 데이터만 반환하므로 다른 평가자 정보는 노출되지 않음

### 2. 쿼리 옵션 (`src/lib/platform.queries.ts`)
- `myReviewQueryOptions(postId, reviewerName)` 추가
  - 닉네임이 비어있으면 비활성(`enabled: false`)
  - `reviewerName`을 queryKey에 포함해 닉네임이 바뀌면 다시 조회

### 3. 평가 폼 (`src/routes/_main.board.$slug.$postNo.tsx`)
- 입력한 닉네임에 디바운스(약 0.5초) 적용해 과도한 조회 방지
- 디바운스된 닉네임으로 `myReviewQueryOptions` 조회
- 조회 결과에 따라:
  - 닉네임칸 아래에 평가 여부 안내 문구 표시 (제출일 포함)
  - 제출 버튼 라벨을 "평가 수정" / "평가 제출"로 전환
  - 별점은 자동으로 채우지 않음 (사용자가 직접 다시 입력)
- 제출 로직(upsert)·중복 방지 동작은 기존 그대로 유지

## 한계
닉네임 기반이라 다른 닉네임을 쓰면 별개의 평가로 처리됩니다. 정확한 본인 식별은 추후 로그인 도입이 필요합니다.

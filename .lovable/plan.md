# 모바일 카드: 제목과 작성자 정보를 분리

모바일 화면에서 일반/공지 카드의 제목과 작성자명·레벨·배지가 한 줄을 공유해 제목이 "[보건] 키..."처럼 과도하게 잘리는 문제를 해결합니다. 모바일에서는 제목이 전체 폭을 쓰고, 작성자 정보는 별도 행으로 분리합니다.

## 동작

- 모바일(<sm): 공지·일반 카드 내부를 세로(`flex-col`)로 배치.
  - 1행: 제목이 전체 폭을 차지, `line-clamp-2`로 두 줄까지 표시.
  - 2행: 작성자명 + Lv + 펼친 배지를 왼쪽에, 조회수/댓글 수를 오른쪽에 배치.
- 데스크톱(sm 이상): 기존처럼 가로 한 줄로 제목(왼쪽)과 메타 정보(오른쪽)를 배치하되, 레벨과 배지는 이미 분리된 구조를 유지합니다.
- 작성자명이 짤리지 않도록 `min-w-0` + `truncate`를 적용하고, 배지는 `expand`로 전체를 펼쳐 표시합니다.

## 기술 사항

- `src/routes/_main.board.$slug.index.tsx`
  - 공지 카드(`notices`)와 일반 카드(`pagedGenerals`)의 `Link` 래퍼 및 메타 정보 마크업을 수정.
  - 반응형: `flex-col sm:flex-row sm:items-center`.
  - 제목 영역: `flex-1 min-w-0`, `line-clamp-2`.
  - 메타 영역: 모바일 `w-full`, 데스크톱 `w-auto shrink-0`.
  - 작성자 행: `User` 아이콘 + `truncate`된 이름 + `AuthorBadge only="level"` + `AuthorBadge only="awards" expand`.
  - 조회수/댓글 수는 별도 `shrink-0` 그룹으로 오른쪽 정렬.
- `src/routes/_main.guide.tsx`
  - 게시판 목록 카드의 모바일 레이아웃 변경을 사용자 가이드에 반영.

## 영향 범위

- 순수 마크업/CSS 조정. 서버·DB·API 호출 변화 없음.
- 링크/프로젝트/문제ZIP/투표 카드는 이미 제목과 작성자가 분리되어 있거나 구조가 달라 이번 변경 대상에서 제외. 필요시 별도 논의.
- 인증/RLS/SSR 영향 없음.

## 검증

- 모바일 좁은 폭에서 공지·일반 카드 제목이 한 줄 전체를 사용하는지 확인.
- 작성자명+레벨+배지가 제목 아래 별도 행으로 나타나는지 확인.
- 데스크톱에서 기존 가로 레이아웃이 유지되는지 확인.
- 가로 스크롤이 발생하지 않는지 확인.

## 문제

게시판 수정 모달에 설정 항목이 많아지면서 모달이 화면 높이를 넘겨 위/아래 내용이 잘립니다. 현재 `DialogContent`에 높이 제한과 스크롤이 없습니다.

## 해결

`src/routes/admin.categories.tsx`의 수정 다이얼로그 `DialogContent`를 수정합니다.

- 모달 최대 높이를 화면의 약 85vh로 고정 (`max-h-[85vh]`)
- 내용(`DialogHeader` + 폼 영역)이 넘칠 경우 세로 스크롤 추가 (`overflow-y-auto`)
- 헤더/푸터는 가능하면 고정하고 중간 폼 영역만 스크롤되도록 정리 (간단하게는 DialogContent 전체에 max-h + overflow-y-auto 적용)

추가하기(생성) 폼도 동일하게 길어질 수 있으나, 요청은 수정 모달이므로 수정 모달에 우선 적용합니다.

## 기대 결과

모달 크기는 화면 안에 고정되고, 설정이 많아지면 모달 안에서 세로 스크롤로 모든 항목을 볼 수 있습니다.

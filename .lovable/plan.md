# 목록 탭에서 "배지 추가" 인라인 동작 수정

## 문제
`admin.profiles.tsx`의 사용자 목록에서 `+`(이 사용자에 배지 추가) 버튼은 `startEdit(p)`를 호출해 **관리 설정 탭의 입력 폼**에 사용자명/배지 값을 채웁니다. 하지만 사용자는 목록 탭에 있으므로 다른 탭에서 폼만 바뀔 뿐 눈앞에서는 아무 반응이 없습니다.

## 해결 (목록 탭 내 인라인 추가)
`+` 버튼을 누르면 해당 사용자 행 바로 아래에 작은 배지 입력 영역이 펼쳐지도록 변경합니다.

- 상태 `addingFor`(사용자 id 또는 null)를 추가.
- `+` 클릭 시 `addingFor`를 해당 사용자 id로 토글(이미 열려 있으면 닫기). 더 이상 다른 탭 폼을 건드리지 않음.
- 펼쳐진 영역: 배지 이름 입력창 + "추가" 버튼 + "취소" 버튼. Enter로도 제출.
- 제출 시 기존 `addAward({ data: { username, name } })` mutation 재사용 → 성공 시 토스트, 쿼리 무효화, 입력 닫기/초기화.
- 빈 값이면 토스트로 안내.

## 추가 정리
- 관리 설정 탭의 폼은 "신규 사용자 등록 + 배지"용으로 그대로 유지(목록의 `+`와 역할 분리).
- 현재 파일은 정상 빌드 상태이며, 보고된 JSX 구문 에러는 편집 도중의 일시적 오류로 보입니다. 적용 시 다시 확인합니다.

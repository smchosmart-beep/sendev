# 결과물 형태 선택지에 "데스크탑 앱" 추가

## 목표
활동기록 03 최종결과물 단계의 "결과물 형태" 선택 항목에 "데스크탑 앱"을 추가한다.

## 변경 범위
- `src/lib/record-schema.ts`의 `OUTPUT_TYPES` 상수 배열에 `"데스크탑 앱"` 항목 추가
  - 현재: `["웹앱", "모바일앱", "챗봇·AI 도구", "자동화 도구", "수업자료·콘텐츠", "/skill"]`
  - 변경: `"데스크탑 앱"`을 추가
- 사용자 가이드(`src/routes/_main.guide.tsx`)에는 결과물 형태 선택지 목록이 없으므로 별도 수정 없음

## 영향 및 부작용 검토
- `OUTPUT_TYPES`는 `RecordEditor`의 select 옵션과 `CasebookDocument` 출력, `record-readme.ts` 라벨 맵핑에서 사용됨
- DB 컬럼 `output_type`은 `max: 200`으로 충분히 여유 있음
- 기존에 저장된 값은 그대로 유지되며, 새 선택지만 추가되는 형태라 데이터 마이그레이션 불필요
- 투표/평가/리드미 등 연동 로직에 영향 없음

## 확인 항목
- `tsgo` 타입체크 통과
- `RecordEditor`에서 "결과물 형태" 드롭다운에 "데스크탑 앱"이 정상 노출

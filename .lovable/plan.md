# PDF 업로드 3MB 제한을 10MB로 상향

## 목표
게시글 첨부파일(PDF 등) 업로드 용량 제한을 현재 3MB에서 10MB로 늘린다.

## 변경 대상

1. `src/lib/file-upload.ts`
   - `MAX_ATTACHMENT_BYTES` 상수를 `10 * 1024 * 1024`로 변경.
   - 이 값은 일반 첨부파일 업로드 함수 `uploadAttachment`에서 크기 검사에 사용된다.

2. `src/routes/_main.guide.tsx`
   - 사용자 가이드에 기재된 첨부파일 용량 안내 문구를 3MB → 10MB로 일괄 변경.
   - 변경 위치: 활동기록 관련 파일 첨부 안내, 본문 이미지/첨부파일 용량 안내.

3. Supabase Storage `post-files` 버킷
   - 버킷의 `file_size_limit`이 3MB 이하로 설정되어 있으면 10MB로 업데이트.
   - 코드만 변경하고 버킷 제한은 그대로면 업로드가 서버에서 거부될 수 있으므로 함께 조정.

## 부작용 검토

- 서버 부하: 단일 파일 크기가 커지면 업로드 시간이 길어지고 스토리지 사용량이 증가하지만, 10MB는 일반 문서/이미지 수준이며 별도 서버 비용 폭증 우려는 없다.
- 기존 기능: `uploadAttachment`를 사용하는 모든 첨부파일 업로드(활동기록 파일, 본문 클립 첨부, 공지 첨부 등)가 동일하게 10MB 기준을 적용받는다. 의도한 범위다.
- 가이드: 용량 안내 문구만 변경되며 다른 설명에는 영향 없다.

## 검증

- 빌드/타입 검사 통과 확인.
- 가이드 페이지에서 "10MB" 문구 정상 노출 확인.
- 5~10MB PDF 파일 업로드 테스트(개발 환경 또는 운영 환경에서) 시 업로드 및 다운로드 정상 동작 확인.

## 문제 / 요구사항

1. 해커톤 탭의 후기 포스트잇이 본문(`max-w-5xl`, 반폭 32rem)을 가림 → 본문을 절대 가리면 안 됨.
2. 후기 포스트잇을 패들렛 담벼락처럼 — **좌우 여백에 각각 2열(두 줄)씩** 카드를 채우는 메이슨리 담벼락.
3. **각 포스트잇 세로 길이는 내용 길이에 따라 다르게** (고정 높이/줄임 없이 내용만큼).

## 해결 (src/components/HackathonReviews.tsx 데스크톱 사이드 컬럼 + 카드 수정)

### 1. 본문을 가리지 않게 위치/표시 조건
- 좌/우 담벼락은 본문 바깥 여백에만 배치(본문 반폭 32rem + 여백 1rem 바깥부터).
- 표시 조건을 `xl`(1280px) → `2xl`(1536px) 이상으로 상향. 그보다 좁으면 사이드 담벼락 숨김.
- 좁은 화면 폴백: `HackathonReviewStripMobile` 표시 조건을 `xl:hidden` → `2xl:hidden`으로 변경(빈틈 없음).

### 2. 패들렛 담벼락 = 각 side 2열 메이슨리
- 기존 단일 `w-64` 컬럼 → 각 side를 **2열 메이슨리**(CSS `columns-2` + `gap`)로. 카드들이 높이 제각각으로 벽돌처럼 쌓임.
- 좌/우 담벼락 폭 각각 약 14~15rem. 위치: 왼쪽 `left-[calc(50%-47rem)]`, 오른쪽 `left-[calc(50%+33rem)]` 부근(1536px 기준 본문과 비겹침).
- 리뷰를 좌/우 번갈아 분배, 각 side 내부 2열로 흐름. 세로 스크롤 유지(`overflow-y-auto`, 스크롤바 숨김). 카드별 살짝 회전·알록달록 postit 색 유지.

### 3. 카드 높이를 내용에 맞게
- `ReviewCard`의 `line-clamp-6` 제거 → 내용 전체가 보이도록 자연 높이.
- 메이슨리에서 카드가 컬럼 사이에서 쪼개지지 않게 `break-inside-avoid` 적용.

## 영향 범위
- UI/표현 코드만 수정. 서버 함수·DB·쿼리·자격 검증 변경 없음.
- 가이드(`/guide`) 후기 설명은 담벼락 표현 한 줄만 보강.

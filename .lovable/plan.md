# 활동기록 이미지 90도 회전 + 관리자 편집 잠금 해제

## 1. 이미지 90도 회전

활동기록(02 문제 정의 과정 등)의 이미지 첨부 칸에 붙은 사진을 오른쪽으로 90도씩 돌릴 수 있게 합니다.

- 각 이미지 미리보기 위에 제거(X) 버튼 옆으로 **회전 버튼**(RotateCw 아이콘)을 추가합니다. 편집 권한이 있을 때만 노출.
- 누르면 브라우저에서 캔버스로 이미지를 90도 회전해 새 JPEG로 다시 업로드하고, 해당 첨부의 URL을 교체합니다(파일명 유지). 회전 중에는 스피너 표시.
- 회전 결과가 원본 URL을 대체하므로 산출물 보기·사례집 PDF·관리자 대시보드 등 다른 화면은 수정 없이 그대로 회전된 사진을 보게 됩니다.
- 회전 후에는 기존 첨부와 동일하게 "저장을 눌러 주세요" 안내를 띄우고, 저장 시 값이 반영됩니다.

기술 상세
- `src/lib/image-upload.ts`에 `rotateImage90(url, name)` 유틸 추가: 이미지를 로드해 캔버스에서 가로/세로를 바꿔 그린 뒤 JPEG Blob 생성. 서명 URL이 CORS로 캔버스 오염을 일으키지 않도록 `fetch` → `blob` → `createImageBitmap` 경로 사용.
- 업로드는 기존 `uploadAttachment`(`src/lib/file-upload.ts`) 재사용, 반환된 새 URL로 `AttachedFile.url`만 교체.
- 회전 결과가 3MB를 넘지 않도록 기존 압축 로직과 같은 품질 단계(0.92→0.5)로 축소 재시도.
- 변경 파일: `src/components/RecordEditor.tsx`(RowItem 이미지 미리보기 영역), `src/lib/image-upload.ts`.

## 2. 관리자도 활동기록 수정

현재 서버 쪽은 이미 관리자 비밀번호를 받으면 팀원이 아니어도 저장을 허용합니다. 다만 화면에서는 관리자 페이지에서 비밀번호를 한 번 입력한 세션에서만 편집이 열리고, 활동기록 페이지 자체에는 관리자 확인 수단이 없습니다.

- 활동기록 상단(편집 권한 없음 안내 문구 자리)에 **"관리자로 수정하기"** 버튼을 추가합니다.
- 누르면 비밀번호 입력 다이얼로그가 뜨고, 기존 관리자 확인 서버 함수로 검증한 뒤 세션에 저장합니다(다른 관리자 화면과 동일한 방식).
- 검증에 성공하면 즉시 편집 모드로 전환되고, 안내 문구는 "관리자 권한으로 편집 중"으로 바뀝니다. 저장 요청에는 이미 관리자 비밀번호가 함께 전송되므로 서버 로직 변경은 없습니다.
- 잘못된 비밀번호는 토스트로 알리고 편집을 열지 않습니다.

기술 상세
- `checkRecordAdmin`(record.functions.ts) + `setAdminPassword`(`src/lib/admin-auth.ts`) 사용, 검증 성공 시 로컬 state로 `canEdit` 재계산.
- 변경 파일: `src/components/RecordEditor.tsx`만.

## 3. 가이드 갱신

`src/routes/_main.guide.tsx` 활동기록 안내에 (1) 이미지 회전 버튼, (2) 관리자 수정 방법 두 줄을 추가합니다.

## 검증

- 타입 체크 통과
- 이미지 첨부 후 회전 버튼 2회 클릭 → 180도 회전 확인, 저장 후 새로고침에도 유지
- 팀원이 아닌 상태에서 관리자 비밀번호 입력 → 편집 가능, 행 저장 성공
- 틀린 비밀번호 → 편집 열리지 않음

# 투표 게시판: 관리자에게도 작성자 익명 적용

## 원인
현재 코드는 투표 종료 전이라도 관리자에게는 작성자를 그대로 보여줍니다.
- `src/components/VoteSection.tsx` 81행: `showAuthor = status === "closed" || isAdmin`
- `src/routes/_main.board.$slug.$postNo.tsx`: 상세 화면도 관리자면 실명 표시
첨부 화면은 관리자 상태(투표 시작/초기화 패널 노출)라 이름이 보인 것이며, 일반 방문자에게는 이미 "익명"으로 표시됩니다.

## 변경
- 투표 후보 카드: 종료(`closed`) 전에는 관리자 포함 모두 "익명" 표시. 관리자 예외 제거.
- 게시글 상세: 투표 글이면 종료 전 작성자 "익명", 레벨·배지도 숨김(관리자 예외 제거).
- 종료 후에는 지금처럼 실명(닉네임)과 배지 표시.
- 전역 검색 마스킹은 이미 적용되어 있어 그대로 유지.

## 유지되는 동작
- 저장된 데이터, 1인 1글 검증, 수정·삭제 권한 로직은 변경 없음(표시만 감춤).
- 관리자 투표 제어(시작/종료/초기화), 종료 후 투표자 명단 표시는 그대로.

## 기술 사항
- `src/components/VoteSection.tsx`: `showAuthor`에서 `isAdmin` 조건 제거.
- `src/routes/_main.board.$slug.$postNo.tsx`: `hideVoteAuthor` 계산에서 관리자 조건 제거.
- 서버·DB 변경 없음.

## 가이드 갱신
- `/guide` 투표 게시판 설명에 "종료 전까지는 관리자도 작성자를 볼 수 없음"을 반영.

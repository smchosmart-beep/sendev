# [인터뷰 기록] 탭 전용 양식

## 목표
활동기록 · 02 문제 정의 과정의 [인터뷰 기록] 탭을 세 항목 흐름으로 작성하게 만든다.

1. 인터뷰 질문
2. 인터뷰 대상
3. 인터뷰 내용 (긴 글 입력)

## 화면 동작
- [인터뷰 기록] 탭을 고르면 기본 양식(언제·어디서 / 무엇을 나눴나요 / 그래서 정한 것 / 링크 / 파일) 대신 위 3개 칸만 보인다.
- 「인터뷰 질문」과 「인터뷰 내용」은 여러 줄 입력, 「인터뷰 대상」은 한 줄 입력.
- 칸마다 예시 문구(플레이스홀더)를 넣는다.
  - 질문: 예) 어떤 상황에서 배수 판별이 가장 어렵나요?
  - 대상: 예) 5학년 학생 3명 / 6학년 담임 교사 1명
  - 내용: 예) 학생들은 3의 배수는 자릿수 합으로 잘 찾지만 …
- 다른 탭(팀빌딩·문제 구체화 회의·그 밖의 메모)의 양식은 그대로 유지된다.

## 긴 글 대응 (보완)
- 현재 입력·저장 모두 칸당 3000자에서 잘려 인터뷰 내용 뒷부분이 소실될 수 있다. 상한을 8000자로 올린다(입력 화면과 저장 검증 양쪽 동시).
- 「인터뷰 내용」 칸 아래에 현재 글자수/상한을 표시해 잘림을 미리 알 수 있게 한다.

## 출력물
- README 출력과 사례집(PDF) 출력에서도 인터뷰 항목 라벨(질문/대상/내용)이 그대로 나오게 한다. 이미 탭별 양식을 참조하는 구조라 라벨만 따라간다.


## 기존 데이터 정리
현재 [인터뷰 기록] 탭에 저장된 기록은 2건이며 모두 테스트 입력("111/222/3333", "끌림에서 …")이다. 라벨이 바뀌면 뜻이 어긋나므로 이 2건은 삭제한다. 다른 탭·다른 섹션 기록은 건드리지 않는다.

## 가이드 갱신
사용자 가이드의 활동기록 설명에 [인터뷰 기록] 탭의 3항목 양식을 추가한다.

## 기술 메모
- `src/lib/record-schema.ts`의 `PROCESS_SUBTYPE_TEMPLATES`에 `"인터뷰 기록"` 항목 추가: `cols: ["인터뷰 질문", "인터뷰 대상", "인터뷰 내용", "", "", ""]`, `longCols: [0, 2]`, 첨부/링크 열 없음.
- 저장 열은 기존 `col1~col3`을 그대로 쓰므로 스키마 변경·마이그레이션 없음.
- `record-readme.ts`, `CasebookDocument.tsx`, `RecordEditor.tsx`는 이미 `rowTemplate(kind, subtype)`을 사용하므로 코드 수정 없이 반영된다(동작 확인만 수행).
- 서버 함수·버킷·비용 증가 없음.

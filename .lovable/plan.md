# (창일중)이서영 닉네임이 조회되지 않는 이유와 처리

## 확인된 사실

데이터를 직접 조회한 결과입니다.

- `창일중(이서영)`이라는 이름은 **투표 기록에만** 존재합니다(투표자 이름/키).
- 프로필 목록에는 이 이름이 **없습니다**. 등록된 프로필은 `이서영` 하나뿐입니다(2026-06-09 등록).
- 글·댓글·활동기록·심사 명단 어디에도 `창일중(이서영)`은 없습니다.

원인: 관리자 프로필 화면은 프로필 표(등록된 닉네임)만 보여줍니다. 이 이름은 프로필이 없는 상태(등록이 해제되었거나 삭제된 것으로 보임)라 검색해도 나오지 않습니다. 이름 표기(괄호) 자체는 문제가 아닙니다 — `(5팀)교사 박태우`처럼 괄호가 든 프로필도 정상 등록되어 있습니다.

## 제안 작업

### 1) 관리자 프로필 목록에 "미등록 닉네임" 포함
프로필 표에 없더라도 글·댓글·투표·활동기록 등에서 실제로 쓰인 닉네임을 목록에 함께 보여줍니다.
- 행에 `미등록` 표시를 붙이고, 비밀번호 초기화 같은 프로필 전용 동작은 숨깁니다.
- 이렇게 하면 이번처럼 "분명 쓰이고 있는데 조회가 안 되는" 상황이 사라집니다.

### 2) 이름 통합(선택)
`창일중(이서영)`의 투표 기록을 `이서영`으로 합치거나, 반대로 프로필 이름을 `창일중(이서영)`으로 바꾸는 정리를 원하시면 기존 관리자 닉네임 변경 기능으로 처리합니다. 어느 쪽으로 맞출지는 결정이 필요합니다.

## 기술 메모

- `src/lib/platform.functions.ts`의 `listUserProfiles`: `user_profiles` 조회에 더해 `posts.author`, `comments.author`, `votes.voter_name`, `record_members.username`에서 쓰인 닉네임 키를 모아, 프로필에 없는 키를 `registered: false` 항목으로 추가 반환합니다. 이미 조회 중인 `getActivityCounts` 결과를 재사용해 추가 쿼리를 최소화합니다.
- `src/routes/admin.profiles.tsx`: `미등록` 배지 표시, 미등록 행에서는 비밀번호 초기화·삭제 대신 안내만 노출. 기존 검색·정렬·필터는 그대로 동작.
- `src/routes/_main.guide.tsx`: 프로필 관리 설명에 "프로필 미등록 닉네임도 목록에 보인다" 문구 추가.
- DB 스키마 변경 없음. 조회는 관리자 화면 1회 로드 시점에만 발생하므로 서버 비용 영향 미미.

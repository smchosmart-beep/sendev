## 문제 요약
별점 평가는 DB에 정상 저장되고 있음(데이터 확인 완료). 사용자가 "반영 안 됨"으로 느끼는 이유는 **본인이 매긴 점수가 제출 후·재방문 시 화면에 다시 표시되지 않기 때문**:
- 제출 성공 직후 별점 상태를 빈 값으로 초기화해 별이 사라짐.
- "내 평가 조회"가 실제 점수를 반환하지 않아 새로고침 시 별점 칸이 항상 비어 있음.

## 목표
저장된 본인 평가 점수를 폼의 별점에 그대로 다시 보여주어, 제출/갱신/재방문 시 "내가 준 별점"이 항상 보이도록 한다.

## 변경 사항

### 1. 서버 함수 (`src/lib/platform.functions.ts`)
- `getMyReview` 반환값에 `scores: Record<string, number>` 추가. 조회 select에 `scores` 포함. 미평가 시 `found: false`(scores 생략).

### 2. 평가 폼 (`src/routes/_main.board.$slug.$postNo.tsx`)
- `myReview`가 `found`이면 반환된 `scores`로 별점 상태(`scores`)를 채우는 동기화 로직 추가(useEffect). 사용자가 입력 중인 변경을 덮어쓰지 않도록, 폼을 아직 건드리지 않은 초기/조회 시점에만 채움.
- 제출 성공 시 `setScores({})`로 비우지 않고, 방금 제출한 점수를 그대로 유지(또는 my-review 재조회 결과로 반영)하여 별이 사라지지 않게 함.
- "이미 평가하셨어요" 상태에서도 본인 별점이 보이도록 자연스럽게 연결.

## 검토 사항
- 기존 저장 데이터와 호환(컬럼/구조 변경 없음, 읽기 필드만 추가).
- 추가 서버 비용 영향 없음(이미 호출되던 조회에 컬럼 하나 추가).
- 닉네임 고정/갱신 흐름, 평가 요약 평균 계산 등 다른 기능에 영향 없음.

# 활동기록 단계 제목 잘림 개선

## 문제
- 활동기록 상단 단계 탭(8개)과 작성 현황 사이드바에서 제목이 짤려 보임.
- 예: `04 개발·교육적 점검` → `개발·교육적...`, `07 README 출력` → `README...`

## 목표
- 폰트 크기를 줄여 긴 제목도 생략 없이 표시.
- 공간이 부족하면 2줄까지 줄바꿈 허용.
- 상단 탭, 사이드바 모두 일관되게 적용.

## 변경 범위
- `src/components/RecordEditor.tsx`
  - 상단 단계 버튼(`<nav aria-label="작성 단계">`)에서 제목 `span`의 `truncate` 제거.
  - 글자 크기를 `text-xs sm:text-sm`에서 더 작은 값으로 조정(예: `text-[10px] sm:text-xs`).
  - 줄 높이 및 최소/최대 높이 조정으로 버튼 높이 균일 유지.
- `src/components/record/StepSidebar.tsx`
  - 블록 제목 `span`의 `truncate` 제거, 폰트 크기 및 줄바꿈 동일하게 적용.
- `src/routes/_main.guide.tsx`
  - UI 변경에 맞춰 가이드 문구가 있다면 필요 최소한만 갱신.

## 검증
- 데스크톱(8개 버튼이 한 줄에 들어오는 너비)에서 8개 단계 제목이 모두 잘리지 않음.
- 모바일(좁은 화면)에서 2줄까지 줄바꿈되며 버튼 레이아웃이 무너지지 않음.
- 사이드바(240px)에서 블록 제목이 잘리지 않음.
- 타입 검증(`bunx tsc --noEmit`) 통과.

## 영향
- 순수 UI 조정: 데이터/스키마/서버 함수 변경 없음.
- 기존 기능(작성, 저장, 출력)에 영향 없음.

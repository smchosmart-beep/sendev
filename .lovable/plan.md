# 활동기록 README의 URL 하이퍼링크 처리

## 문제
최종 README에서 배포 주소·GitHub·시연 영상 URL이 그냥 글자로만 나오고 클릭이 안 됩니다.
원인은 두 가지입니다.

1. README 마크다운을 만들 때 URL을 링크 문법이 아닌 맨 텍스트(`- 배포 주소: https://...`)로 넣고 있습니다.
2. 미리보기 렌더러에 GFM(자동 링크) 확장이 꺼져 있어 맨 URL이 링크로 변환되지 않습니다.

## 수정 내용

1. `src/lib/record-readme.ts`
   - 배포 주소 / GitHub / 시연 영상 줄을 마크다운 링크 문법으로 변경
     (`- 배포 주소: [https://...](https://...)`).
   - `http`/`https`가 빠진 입력은 `https://`를 앞에 붙여 보정한 뒤 링크로 만들고, 화면에 보이는 글자는 사용자가 입력한 원문 그대로 유지.
   - 이 함수는 화면 미리보기·`.md` 내려받기·관리자 ZIP의 공개용 README에서 공통으로 쓰이므로 세 곳 모두 한 번에 고쳐집니다.

2. `src/components/RecordOutput.tsx`
   - 이미 설치돼 있는 `remark-gfm`을 미리보기 렌더러에 연결해, 앞으로 다른 곳에 적힌 맨 URL도 자동으로 링크가 되도록 합니다.
   - 링크는 새 탭으로 열리도록 처리(`target="_blank"`, `rel="noopener noreferrer"`).

## 영향 범위
표시·문자열 생성만 바뀝니다. DB, 서버 함수, 저장 로직, 블록 상태(미작성/작성중/작성완료) 판정에는 변화가 없습니다.

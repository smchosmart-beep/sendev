## 문제

모바일에서 글 목록 카드의 오른쪽 작성자 이름(예: "김효진")이 좁은 공간 때문에 "김효 / 진"처럼 두 줄로 줄바꿈됩니다. 제목이 길어지면 작성자 영역이 눌려서 발생합니다.

## 해결

`src/routes/_main.board.$slug.index.tsx`의 글 목록 카드(공지사항/질문게시판/일반게시판 3곳, 그리고 하단 `PostCard` 컴포넌트)에서 작성자/메타 영역이 줄어들지 않고 한 줄로 유지되도록 조정합니다.

- 작성자 이름을 감싸는 `<span>`(아이콘 + 이름)에 `whitespace-nowrap` 추가 → 이름이 절대 줄바꿈되지 않음.
- 오른쪽 메타 영역(댓글 수 + 작성자) 컨테이너에 `shrink-0` 추가 → 제목이 길어도 메타 영역이 눌리지 않음.
- 왼쪽 제목 `<span>`에 `min-w-0 truncate` 추가 → 제목이 길면 작성자 대신 제목이 말줄임(…)으로 잘림.

이렇게 하면 작성자 이름은 항상 한 줄로 표시되고, 공간이 부족할 때는 제목이 줄어듭니다.

## 적용 위치

`src/routes/_main.board.$slug.index.tsx` 내 동일 패턴 4곳:
- 공지사항 목록 (n.author)
- 질문게시판 목록 (q.author)
- 일반게시판 목록 (g.author)
- 하단 `PostCard` 컴포넌트의 작성자 표시

다른 파일/로직 변경은 없습니다.

# 모바일 햄버거 메뉴 오른쪽 끝 정렬

## 목표
- 모바일 화면에서 헤더의 햄버거 메뉴 버튼이 오른쪽 끝에 정렬되도록 한다.
- 로고는 왼쪽 끝에 그대로 유지한다.

## 현재 문제
- `src/routes/_main.tsx` 헤더가 `grid-cols-[auto_minmax(0,1fr)_auto]`로 구성되어 있다.
- 데스크탑 수평 메뉴(`nav`)가 모바일에서는 `hidden sm:flex`로 숨겨지면서 중간 열이 축소되고, 로고와 오른쪽 버튼 그룹이 가까워져 햄버거가 시각적으로 오른쪽 끝에 있지 않게 보인다.

## 구현 내용

### 1. 헤더 레이아웃 변경
- 파일: `src/routes/_main.tsx`
- 헤더 내부 컨테이너를 `grid`에서 `flex justify-between`으로 변경한다.
- 왼쪽 영역: 로고(SEN DEV CONNECT)
- 중앙 영역: 데스크탑 수평 메뉴 (`hidden sm:flex`)
- 오른쪽 영역: 검색/내 페이지/관리자/메뉴 접기/햄버거 버튼

이렇게 하면 모바일에서는 수평 메뉴가 숨겨져도 로고와 오른쪽 버튼 그룹이 양쪽 끝으로 밀려 햄버거 메뉴가 오른쪽 끝에 위치한다.

## 영향 범위
- 변경 파일: `src/routes/_main.tsx`
- 의존성: 추가 없음
- 데이터/서버/DB: 변경 없음
- 사용자 가이드: 변경 없음 (순수 레이아웃 조정)

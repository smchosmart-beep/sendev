# 투표 결과 순위 표기 개선

## 문제
현재 순위 배지는 카드가 화면에 놓인 순서(정렬 후 인덱스)로 매겨집니다. 그래서 같은 표를 받은 글이 여러 개여도 하나만 3위 배지를 받고, 나머지는 배지가 사라집니다. 1차 투표에서 모두 같은 표를 받아도 1·2·3위가 임의로 갈립니다.

## 개선 내용
1. 순위를 표 수 기준으로 계산합니다(표준 경쟁 순위). 같은 표 수는 같은 순위, 다음 순위는 인원수만큼 건너뜁니다.
   - 예: 2표, 2표, 1표, 1표 → 공동 1위, 공동 1위, 공동 3위, 공동 3위
   - 모두 같은 표 → 전원 "공동 1위"
2. 같은 순위인 글이 2개 이상이면 배지 문구를 "공동 N위"로 표시합니다.
3. 순위 배지는 페이지 위치와 무관하게 계산되므로, 2페이지에 있어도 3위 이내면 배지가 붙습니다.
4. 0표인 글에는 순위 배지를 붙이지 않습니다(현재는 3위 안에 들면 붙을 수 있음).
5. "선발" 배지와 동점 안내 문구(결선 투표) 로직은 그대로 유지합니다.

## 기술 세부
- 파일: `src/components/VoteSection.tsx`
- `ordered`(표 내림차순 정렬 결과)로부터 `rankMap: Map<postId, {rank, tied}>`를 `useMemo`로 계산합니다. 정렬은 이미 표 기준이므로 앞에서부터 순회하며 표 수가 바뀔 때만 `rank = index + 1`로 갱신하고, 같은 표 수의 개수를 세어 `tied` 여부를 기록합니다.
- 카드 렌더링에서 인덱스 기반 `rank` 계산을 제거하고 `rankMap.get(post.id)`를 사용합니다. 표시 조건: `status === "closed" && rank <= 3 && count > 0`.
- 배지 문구: `tied ? \`공동 ${rank}위\` : \`${rank}위\``.
- 서버/DB 변경 없음. 표시 로직만 수정합니다.

## 목표

헤더에 똑같은 사람 모양 아이콘이 두 개(① 내 닉네임 설정 / ② 내 페이지) 있어 혼란스러운 문제를 해결합니다. 아이콘을 **하나(내 페이지)로 통합**하고, 닉네임 저장(기기 저장) 기능을 **내 페이지 안으로** 옮깁니다.

## 변경 내용

### 1. 헤더에서 중복 아이콘 제거 (`src/routes/_main.tsx`)
- 데스크톱 헤더의 `<NicknameSetup variant="icon" />`(160라인) 제거.
- 모바일 메뉴의 `<NicknameSetup variant="menu" />` 블록(255~257라인) 제거.
- 결과: 사람 아이콘은 `/mypage`로 가는 "내 페이지" 하나만 남습니다.

### 2. 내 페이지 안에 닉네임 저장 기능 통합 (`src/routes/_main.mypage.tsx`)
- **로그인 화면**: 닉네임/비밀번호 입력 폼 아래에 "이 기기에 저장" 체크박스를 추가. 로그인 성공 시 체크되어 있으면 입력한 닉네임·비밀번호를 이 기기에 저장(`useStoredIdentity.save`)해 글·댓글 작성 시 자동 입력되도록 함.
- **대시보드 화면**: 상단에 현재 저장 상태 표시와 "기기 저장 해제"(`clear`) 버튼을 추가해, 기존 닉네임 설정 다이얼로그가 하던 저장/지우기를 그대로 대체.
- 안내 문구로 "닉네임을 처음 쓰면 비밀번호가 등록되고, 다음부터 같은 비밀번호로 인증됨"을 함께 보여줌.

### 3. 정리
- `NicknameSetup` 컴포넌트는 더 이상 사용되지 않으면 import만 제거(파일은 남겨두거나 삭제). 동작상 영향 없음.

## 동작 흐름 (변경 후)
- 사람 아이콘 클릭 → `/mypage` → 닉네임 + 닉네임 비밀번호 입력 후 로그인 → 대시보드(내가 쓴 글/댓글 반응/좋아요) 확인.
- 같은 화면에서 "이 기기에 저장"으로 자동 입력 설정 및 해제까지 한 곳에서 처리.

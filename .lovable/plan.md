## 목표
공지사항·질문게시판·일반게시판의 각 게시물 목록 항목에 "댓글 수"를 표시한다.

## 변경 사항

### 1. 서버 (`src/lib/platform.functions.ts`)
- `PostDTO`에 `commentCount: number` 필드 추가.
- `listPosts` 핸들러에서, 해당 카테고리의 게시물 id 목록에 대한 댓글을 한 번에 조회(`comments`에서 `post_id`만 select, `in` 필터)해 게시물별 개수를 집계한 뒤 각 게시물에 합산. (답글 포함 전체 댓글 수)
- `mapPost`는 카운트를 인자로 받도록 보완하거나, `listPosts`에서 매핑 후 `commentCount`를 채워 넣음. `getPost` 등 단건 조회는 기존대로 0 기본값 유지(목록 표시에만 필요).

### 2. 목록 UI (`src/routes/_main.board.$slug.index.tsx`)
- 공지사항·질문게시판·일반게시판 각 항목의 작성자 표시 옆에, 댓글 수가 1개 이상일 때 말풍선 아이콘 + 숫자를 함께 표시(예: 💬 3). 0개면 표시하지 않음.
- 기존 작성자(User 아이콘) 표기와 같은 줄에 자연스럽게 배치.

## 검토 사항
- 추가 쿼리 1회(카테고리 내 댓글 id 조회)로 비용 최소화, N+1 없음.
- 산출물 게시판 등 다른 영역에는 영향 없음(요청 범위인 3개 게시판에만 표기).
- 기존 데이터/스키마 변경 없음(읽기 집계만 추가).

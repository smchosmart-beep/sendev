## 관리자 "공지사항 관리" 탭 제거

공지 작성이 상단 고정 버튼 방식으로 전환되었으므로, 중복되는 관리자 메뉴의 "공지사항 관리" 탭을 제거합니다.

### 변경 대상

1. **`src/routes/admin.tsx`**
   - `tabs` 배열에서 `{ to: "/admin/notices", label: "공지사항 관리", icon: Megaphone }` 항목 제거
   - 더 이상 사용하지 않는 `Megaphone` 아이콘 import 정리

2. **`src/routes/admin.notices.tsx`** (라우트 파일)
   - 파일 삭제 → `/admin/notices` 경로 자체를 제거
   - 라우트 트리는 빌드 시 자동 재생성됨

3. **`src/routes/_main.guide.tsx`** (사용자 가이드)
   - "공지사항 관리" 관련 설명이 있는지 확인 후, 있으면 상단 고정 버튼 방식으로 안내 문구 업데이트 (현재 검색상 직접 언급은 없음)

### 참고
- 공지 작성/관리 기능 자체는 상단 고정 버튼 흐름에 이미 존재하므로, 이 작업은 중복 진입점(관리자 탭)만 정리합니다.

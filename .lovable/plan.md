## 목표
"개발 노트" 같은 일반 게시글에 **답글(다음 편)**을 이어 붙여 하나의 연재 시리즈처럼 보이게 합니다. 부모-자식 체인 구조이며, 누구나 이어서 작성할 수 있고, 연재 목록은 글 상세 하단에 표시합니다. 글 이동 시에는 연재 전체가 함께 이동합니다.

## 동작 방식
- 글 상세 하단에 **"다음 편 작성(답글)"** 버튼 → 현재 글을 부모로 하는 새 글 작성으로 이동
- 상세 하단에 같은 연재(체인) 전체 편 목록을 작성순으로 표시(현재 편 강조) + 이전/다음 편 이동
- 연재가 1편뿐이면 "다음 편 작성" 버튼만 노출
- 관리자가 글을 다른 카테고리로 이동하면 연결된 연재 전체가 함께 이동

## 작업 내용

### 1. 데이터베이스 (마이그레이션)
- `posts`에 `parent_post_id uuid` 추가 (자기 참조 FK, 부모 삭제 시 `SET NULL`), 인덱스 추가
- **체인 조회 RPC**: 특정 글이 속한 전체 체인(루트→모든 후손)을 작성순으로 반환하는 재귀 CTE. **`CYCLE` 절 + 깊이 제한(최대 100)**으로 무한루프 방지, 같은 카테고리 내로 한정
- **체인 이동 RPC(트랜잭션)**: 한 글의 연결된 체인 전체를 대상 카테고리로 **단일 트랜잭션**으로 이동. 작성순으로 `max(post_no)+1, +2, …` 연속 부여(전부 이동 또는 전부 취소). 기준 글의 새 `post_no` 반환

### 2. 백엔드 (`src/lib/platform.functions.ts`)
- `PostDTO`에 `parentPostId` 추가 (`POST_COLUMNS`, `mapPost` 반영 — 가법적이라 기존 사용처 안전)
- `createPost` 입력에 `parentPostId`(옵션) 추가. 저장 시 검증: 부모가 **존재 + 동일 카테고리**일 때만 연결, 자기 자신·자기 후손을 부모로 지정 금지
- 체인 조회 서버 함수 `listPostChain(postId)` → 위 조회 RPC를 단일 왕복 호출
- **`movePost` 보강**: 단건 update 대신 위 **체인 이동 RPC** 호출로 전환. 관리자 전용 동작 유지, 기준 글의 새 `postNo`·slug 반환해 리다이렉트 유지

### 3. 작성 화면 (`src/routes/_main.board.$slug.new-general.tsx`)
- `parent`(부모 post_no) 검색 파라미터를 받아 부모 글 id로 해석 → `createPost`에 `parentPostId` 전달
- 부모가 있을 때 상단에 "○○에 이어지는 다음 편 작성 중" 안내 표시

### 4. 상세 화면 (`src/routes/_main.board.$slug.$postNo.tsx`)
- 일반 글(`type === "post"`)에 한해 하단에 **연재 섹션** 추가:
  - "다음 편 작성" 버튼(누구나) → `new-general`로 `parent` 파라미터와 함께 이동
  - 체인 전체 편 목록(제목 + 순번) 표시, 현재 편 강조
  - 이전 편 / 다음 편 이동 버튼

### 5. 사용자 가이드 업데이트 (`src/routes/_main.guide.tsx`)
- 연재(답글로 이어 쓰기) 사용법, 이동 시 연재 전체 동반 이동 동작 설명 추가

## 부작용/안전장치 요약
- 체인 조회·이동 모두 **단일 RPC/트랜잭션** → 서버 비용 과다 및 데이터 분리 방지
- 재귀 **순환/깊이 방어**로 무한 루프 차단
- 답글은 **부모와 동일 카테고리** 강제, 이동 시 **체인 전체 동반 이동** → 이전/다음 링크 항상 유효
- nullable 컬럼·가법적 DTO·옵션 파라미터라 기존 글/프로젝트/링크/질문/검색/SSR 기능에 영향 없음
- `movePost`는 관리자(마스터 비밀번호) 전용이라 일반 사용자 경로 영향 없음
- 부모 삭제 시 자식 보존(`SET NULL`), 작성 권한은 기존 닉네임 소유권 검증 재사용 → 신규 보안 구멍 없음

## 기술 메모
- 연재 식별은 `parent_post_id` 체인 기준이며, 기존 영상용 `series`(문자열) 필드와는 별개입니다.
- 분기가 생기더라도 목록은 루트 기준 후손을 작성순 평면 나열로 표시합니다.

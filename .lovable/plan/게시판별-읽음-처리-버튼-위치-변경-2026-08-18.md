# 게시판별 읽음 처리 버튼 위치 변경

## 현재 상태

- `src/routes/_main.board.$slug.index.tsx`에서 "이 게시판 읽음 처리" 버튼은 검색창 아래, 오른쪽 끝에 혼자 배치되어 있습니다.
- 사용자가 원하는 위치는 "일반게시판" 섹션 헤더의 "글 등록" 버튼 왼쪽입니다.

## 수정 방향

1. **기존 위치 제거**: 검색창 아래에 있는 `MarkAllReadButton` 블록을 삭제합니다.
2. **새 위치 배치**: "일반게시판" 섹션 제목(`<h2>`)과 "글 등록" 버튼이 있는 헤더 행에 읽음 처리 버튼을 추가합니다. 버튼은 글등록 버튼의 왼쪽, 제목과 글등록 버튼 사이에 위치합니다.
3. **UI 정리**: 두 버튼이 한 줄에 자연스럽게 배치되도록 `gap-2` 등의 flex 간격을 사용합니다. 모바일에서 공간이 부족하면 버튼 라벨이 줄어들거나 아이콘 중심으로 표시되지 않도록, 현재 `MarkAllReadButton`의 `label` prop을 유지하되 필요 시 `className`으로 조정합니다.

## 대상 파일

- `src/routes/_main.board.$slug.index.tsx` (변경만 수행)

## 기술 세부

- 기존에 계산된 `boardUnreadCount`와 `category.id`를 그대로 재사용합니다. 추가 데이터 로직이나 서버 함수는 없습니다.
- 버튼은 닉네임이 등록된 경우(`hasReader`)에만 표시되므로, "글 등록" 버튼과 같은 조건부 렌더링 범위 안에 배치할 수 있습니다. 단, 읽음 처리 버튼은 닉네임 등록 여부에 따라, 글등록 버튼은 `category.enablePost`에 따라 노출되므로 두 조건이 모두 필요한 영역에 배치합니다.
- 별도 가이드 업데이트는 없습니다(이미 가이드에 설명이 있음).

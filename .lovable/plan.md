# README 미리보기 영역 너비 확대

## 목적

`/readme` 페이지의 실시간 마크다운 미리보기 영역 가로 폭을 현재 두 배로 늘려 가독성을 높입니다.

## 현재 상태

- `src/routes/_main.readme.tsx`의 좌/우 레이아웃은 `lg:grid-cols-2`로 1:1 분할되어 있습니다.
- 미리보기는 우측 영역에 표시되며, 코드 블록이나 표가 좁게 잘려 보일 수 있습니다.

## 변경 계획

1. **그리드 비율 조정**
   - `lg:grid-cols-2` → `lg:grid-cols-[minmax(0,1fr)_minmax(0,2fr)]`로 변경
   - 입력 폼은 1fr, 미리보기는 2fr을 차지하도록 해 미리보기가 전체 가로의 약 2/3를 사용하도록 합니다.

2. **반응형 안전성**
   - `minmax(0, …)`로 폼/미리보기 모두 `0` 이하로 줄어들지 않도록 보호합니다.
   - `lg` 미만 화면에서는 기존처럼 한 열(위/아래)로 쌓입니다.

3. **내부 콘텐츠 넘침 방지**
   - 미리보기 영역이 넓어져도 `max-w-none`을 유지하고, 코드 블록/표가 가로 스크롤 없이 표시될 수 있도록 `overflow-x-auto`를 검토합니다.

## 영향 범위

- `src/routes/_main.readme.tsx` 한 파일만 수정합니다.
- 다른 페이지, 기능, DB 호출에는 영향을 주지 않습니다.

## 검증

- 빌드 오류가 없는지 확인합니다.
- `/readme` 페이지에서 입력 폼이 좁아지지 않고 미리보기가 확장된 너비로 표시되는지 확인합니다.

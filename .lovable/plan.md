# 활동기록 사례집 PDF 출력 (08 단계)

활동기록에 입력한 내용을 A4 지면으로 조판해 브라우저 인쇄(→ PDF로 저장)로 뽑을 수 있게 합니다. 팀별 출력은 활동기록 08 단계에서, 전체 합본은 관리자 활동기록 현황(/admin/records)에서 제공합니다.

## 지면 구성 (팀 1건, 8쪽 내외)

```text
표지        팀명 · 프로젝트명 · 한 줄 설명 · 대표 이미지 · 팀원 목록 · 발행일
p1 개요     문제영역/주 사용자/결과물 유형/태그/배포상태 · 해결하려는 문제 · 해결 방식 · 링크 배지
p2 결과물   핵심 기능 표 · 사용 흐름 · 기술 스택 · 현재 한계 · 다음 계획
p3 문제정의 종류별 기록 카드(제목·내용·작성자·링크) 시간순
p4 개발기록 자유 기록 + 바꾼 판단 · 막혔던 순간
p5 점검     교사와 학생의 자리 4문항 · AI 활용/사람 확인 · AI 실수 사례
p6 안전     입력·전송·저장 정보 표 · 위험과 대응 · 검증
p7 후기     팀원별 개인 후기·약속 (인원 수만큼 이어짐)
p8 윤리     윤리 설문 문항별 평균 별점 막대 + 추가 다짐
```

- 빈 항목은 지면에서 통째로 생략합니다(빈 제목만 남는 쪽 없음). 내용량에 따라 실제 쪽수는 6~10쪽으로 자연스럽게 늘고 줄어듭니다.
- 각 쪽 하단에 얇은 러닝풋(팀명 · 섹션명 · 쪽번호)을 둡니다.

## 디자인 톤 — 교육자료 정갈형

- 넉넉한 여백(A4, 상하 18mm / 좌우 16mm), 얇은 헤어라인 구분선, 본문은 검정에 가까운 회색.
- 포인트 색은 사이트 primary 토큰 한 가지만 사용(섹션 번호, 러닝 헤드, 표 헤더 배경 아주 옅게).
- 제목은 큰 번호 + 국문 제목, 본문 10.5pt / 캡션 8.5pt 수준. 표는 세로선 없이 가로 헤어라인만.
- 화면(미리보기)에서도 같은 지면을 종이처럼 흰 카드로 겹쳐 보여 줍니다.

## 동작

- 08 단계: `사례집 미리보기`가 바로 보이고 상단에 **인쇄·PDF 저장** 버튼. 클릭 시 `window.print()`.
- 관리자 전체 합본: `/admin/records`에 **사례집 합본 인쇄** 버튼. 팀 순서대로 지면을 이어 붙이고 맨 앞에 목차 1쪽(팀명 · 프로젝트명 · 쪽 시작 표시)을 둡니다.
- 인쇄 시 사이트 헤더/네비/버튼은 숨기고 지면만 남깁니다(기존 README 인쇄 규칙과 같은 방식).

## 기술 메모

- 새 파일 `src/components/record/CasebookDocument.tsx`: `RecordOverviewTeam` 하나를 받아 지면 전체를 렌더링. 데이터는 이미 08 단계에서 쓰는 것과 동일한 번들(`bundle.*`)이라 서버 함수 추가 없음.
- 쪽 단위 조판은 CSS만 사용: `.casebook-page { width: 210mm; min-height: 297mm; break-after: page; }`, 카드/표에 `break-inside: avoid`. 라이브러리 추가 없음 → 서버 비용 0, 한글 폰트 문제 없음.
- 인쇄 스타일은 `src/styles.css`의 기존 `@media print` 블록 아래에 `body:has(.casebook-root)` 스코프로 별도 규칙 추가. 기존 README 인쇄 규칙(`.record-output [data-print-root]`)은 그대로 두어 07 단계 동작에 영향 없음.
- `RecordEditor.tsx`의 `step === 7` 자리표시 섹션을 `CasebookDocument` 렌더링으로 교체(07과 동일한 team 객체 전달).
- 관리자 합본: `admin.records.tsx`에서 이미 불러온 `getRecordOverview` 결과의 `teams`를 순회해 같은 컴포넌트를 렌더링하되, **버튼을 누른 뒤에야 지면을 만드는 지연 렌더링**으로 처리합니다. 평소에는 아무것도 렌더링하지 않고, 클릭 시 상태를 켜 지면을 붙인 다음 이미지 로딩(`img.decode()` 또는 `onload` 집계)이 끝나면 `window.print()`를 호출합니다. 이미지에는 `loading="eager"`를 지정해 인쇄 시점에 빈 칸이 남지 않게 하고, 인쇄 대화상자가 닫히면(`afterprint`) 지면을 다시 내려 평소 화면이 무거워지지 않도록 합니다. 추가 조회는 없습니다.
- 라벨/문구는 `src/lib/record-schema.ts`의 기존 정의를 재사용하고, 값 정리(빈 값 판정·링크 프로토콜 보정)는 `src/lib/record-readme.ts`의 기존 헬퍼를 재사용합니다. 이때 `record-readme.ts`의 `normalizeUrl`을 `export`로 바꿔 사례집 컴포넌트에서 그대로 씁니다(내부 호출부는 그대로라 기존 README 출력에 영향 없음).
- 대표 이미지는 이미 업로드된 URL을 그대로 사용하며, 인쇄 시 잘리지 않도록 지면 폭에 맞춰 축소합니다.

## 부작용 점검

- 서버 함수·쿼리 추가 없음 → 요청량/비용 변화 없음.
- 08 단계는 지금 빈 자리표시라 기존 동작을 대체해도 회귀 위험 없음. 인쇄 CSS는 새 선택자로 격리.
- 관리자 페이지는 버튼 1개와 숨겨진 인쇄 영역만 추가(화면 기본 레이아웃 변경 없음).

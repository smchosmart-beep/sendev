# 유튜브 강의 시리즈 묶음 기능

같은 강의 시리즈를 **대표 카드 1개**로 묶고, 카드를 누르면 해당 시리즈의
에피소드 목록 상세 화면으로 이동합니다. 시리즈는 **링크 게시판에만** 적용하며,
시리즈를 입력하지 않은 단독 영상은 기존처럼 개별 카드로 함께 노출합니다.

## 동작 흐름

```text
[유튜브 강의 게시판]
  ├─ 📺 양실장의 바이브코딩 대학 (7개)   ← 시리즈 대표 카드
  ├─ 📺 다른 시리즈 ...
  └─ 🎬 단독 영상                          ← 시리즈 미입력, 개별 카드

  (시리즈 카드 클릭)
        ↓
[시리즈 상세]  /board/$slug/series/$series
  ├─ ep1 : 프론트엔드
  ├─ ...
  └─ ep7 : RAG 챗봇   → 각 영상 상세로 연결
```

## 구현 내용

### 1. 데이터: 시리즈 필드 추가
- `posts` 테이블에 `series` (text, 기본값 `''`) 컬럼 추가.
- 빈 값이면 "단독 영상"으로 취급.
- `PostDTO` 및 조회/저장 서버 함수에 `series` 포함.

### 2. 링크 등록 폼: 시리즈 선택/입력
- `_main.board.$slug.new-link.tsx`에 **시리즈** 입력란 추가.
- 이미 등록된 시리즈명을 추천(드롭다운)하면서 새 시리즈명도 직접 입력 가능한
  콤보 형태. 비워두면 단독 영상으로 등록.
- 링크 게시판에만 적용(산출물 폼은 변경하지 않음).

### 3. 게시판 화면: 시리즈 단위 묶음
- 링크 섹션에서 게시물을 `series` 기준으로 그룹화.
- 시리즈가 있는 그룹 → 대표 카드 1개(시리즈명 + 영상 개수 + 대표 썸네일).
- 시리즈 미입력 항목 → 기존처럼 개별 카드로 함께 노출.
- 대표 카드 썸네일은 그룹 내 첫 영상의 og 이미지 사용.

### 4. 시리즈 상세 화면 (새 라우트)
- `_main.board.$slug.series.$series.tsx` 추가.
- 해당 시리즈 영상들을 ep 순서대로 카드 목록으로 표시.
- 각 카드 → 기존 영상 상세(`/board/$slug/$postNo`)로 연결.

## 기술 메모
- DB: 마이그레이션으로 `posts.series` 추가.
- 정렬: 제목 안의 `ep` 숫자를 파싱해 오름차순(없으면 등록순).
- 그룹화는 화면(컴포넌트) 단에서 처리 — 기존 조회 쿼리 구조 유지.

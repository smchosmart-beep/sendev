## 문제

질문/일반 게시판이 "글 게시판"(`type === "post"`)으로 통합되면서, **글쓰기 폼**(`/board/{slug}/new-general`)에는 "상단 고정(공지)" 체크박스가 제목 아래에 있습니다. 하지만 **글 수정 모달**(스크린샷의 "글 수정" 화면)에는 이 체크박스가 빠져 있어, 작성 후에는 고정 여부를 바꿀 수 없습니다.

서버 함수 `updatePost`는 이미 `pinned` 값을 받아 저장할 수 있으므로, 프론트엔드(수정 모달)만 보완하면 됩니다.

## 변경 사항 (UI 전용)

파일: `src/routes/_main.board.$slug.$postNo.tsx` (수정 모달이 있는 `ManagePost` 컴포넌트)

1. **상태 추가**: 다른 편집 상태들과 함께 `pinned` 상태 추가, 초기값은 `post.pinned`.
2. **게이트 통과 시 동기화**: 비밀번호 확인 후 폼을 열 때(`editGateMutation` 성공 콜백) `pinned`도 `post.pinned`로 다시 설정.
3. **수정 요청에 포함**: `editMutation`에서 게시글(`isBoardPost`)일 때 `update(...)` 데이터에 `pinned`를 추가로 전달.
4. **체크박스 UI**: 수정 모달의 글 게시판 분기(제목/내용/작성자 영역) 안에, 작성 폼과 동일하게 "상단 고정(공지)" 체크박스를 추가. 기존 `Checkbox` 컴포넌트와 동일한 스타일/라벨 사용.

## 가이드 업데이트

`src/routes/_main.guide.tsx`의 "글쓰기와 공지" 설명에 글 작성뿐 아니라 **글 수정 시에도** 상단 고정을 켜고 끌 수 있다는 문구를 한 줄 보완.

## 검증

- 글 게시판 글의 "수정"을 열어 체크박스가 보이고, 현재 고정 상태가 반영되는지 확인.
- 체크/해제 후 저장 시 목록 상단 고정 여부가 바뀌는지 확인.

## 목표
본문 단독 링크 미리보기 카드(`LinkPreviewCard`)에서 녹색 미리보기 영역이 위쪽으로 쏠려 보이는 문제를 해결합니다. 녹색 영역을 카드 안에서 상·하·좌·우 균등한 여백으로 감싸 안정적으로 보이게 합니다.

## 현재 동작
`LinkPreviewCard`(src/routes/_main.board.$slug.$postNo.tsx, 833줄~)는 `<a>`에 `overflow-hidden`이 걸려 있고 녹색 영역(`bg-accent` span)이 카드의 상단·좌우 모서리에 꽉 차게 붙습니다. 그 결과 녹색 영역 위쪽에는 여백이 없고, 텍스트 영역의 좌우 패딩과 대비되어 위로 쏠려 보입니다.

## 작업 내용 (UI/표시만)
1. `<a>` 컨테이너에서 `overflow-hidden`을 제거하고 균일한 내부 패딩(예: `p-3`)을 추가.
2. 녹색 미리보기 영역(span)에 둥근 모서리(`rounded-xl`)를 적용해, 카드 안에서 상·좌·우 동일한 여백으로 떠 있는 썸네일 형태로 변경.
3. 텍스트 영역(제목 + 사이트명) span의 패딩을 외부 패딩과 중복되지 않도록 조정(좌우 `p-4` → 상하 약간만 두는 식으로 정리)하여 전체 간격을 균형 있게 맞춤.
4. 데스크톱 가로 배치(`sm:flex-row`, `sm:w-64`)에서도 여백이 자연스럽도록 확인.

## 범위/안전
- 순수 렌더링(레이아웃/여백) 변경이며 데이터·서버·DB 변경 없음.
- OG 이미지가 있는 링크/구글 드라이브 아이콘 표시 동작은 그대로 유지.
- 다른 카드(LinkEmbedSection 등)에는 영향 없음.

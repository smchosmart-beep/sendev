# 대표 이미지: 주소 입력 → 파일 업로드

03 최종 결과물 단계의 `대표 이미지 주소` 텍스트 입력을 파일 업로드 방식으로 바꿉니다.

## 동작

- `대표 이미지` 항목에 [이미지 선택] 버튼을 둡니다. 파일을 고르면 자동으로 용량·크기를 줄여 업로드하고, 업로드된 이미지가 바로 미리보기로 보입니다.
- 업로드가 끝나면 저장 값(이미지 주소)이 자동으로 채워지고 기존 자동 저장 흐름을 그대로 탑니다.
- [제거] 버튼으로 이미지를 비울 수 있습니다.
- 업로드 중에는 버튼이 비활성화되고 스피너가 돌며, 실패 시 토스트로 안내합니다.

## 기술 메모

- 새 저장소·새 서버 함수·DB 변경 없음. `heroImageUrl` 필드(`hero_image_url` 컬럼)는 그대로 두고 값만 업로드된 이미지 주소로 채웁니다.
- 업로드는 이미 쓰고 있는 `src/lib/image-upload.ts`의 `uploadCommentImage`(post-images 버킷 + 압축 + 장기 서명 URL)를 재사용합니다.
- `src/components/RecordEditor.tsx`의 `FinalInput` 타입에 `type: "image"`를 추가하고, `heroImageUrl` 항목만 이 타입으로 바꿉니다. 렌더러(`FinalField`)에 이미지 입력 분기를 추가합니다.
- README 출력(`record-readme.ts`)은 이미 `heroImageUrl`을 이미지 주소로 쓰므로 수정 불필요.
- 가이드(`/guide`) 활동기록 03단계 설명에서 "대표 이미지 주소" 문구를 "대표 이미지 파일 업로드"로 갱신합니다.

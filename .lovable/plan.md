# 결선 종료 후 최종 순위를 이어서 매기기

## 문제

투표가 끝난 뒤 최종 명단에서, 1차에서 먼저 확정된 10팀에는 순위가 붙지 않고, 결선에서 뽑힌 2팀이 "1위, 2위"로 표시됩니다.

원인(코드 확인 완료, `src/components/VoteSection.tsx`):
- 순위 계산(`rankMap`, 237-256행)이 **이번 결선 후보만** 대상으로 하고, 순위를 1부터 다시 시작합니다.
- 확정 팀은 순위 표시에서 아예 제외됩니다(`rankInfo = showFinal && isLocked ? undefined : ...`, 432행).
- 배지는 3위 이내에서만 노출됩니다(434행).

## 수정 내용

1. 결선 종료 화면에서 순위를 **한 줄로 이어서** 매깁니다.
   - 먼저 1차 확정 팀을 그 라운드 득표수 기준으로 1위부터(동점은 공동 순위, 다음 순위는 인원수만큼 건너뜀).
   - 그다음 결선 후보를 **확정 팀 수 다음 번호부터** 이어서 매깁니다. 예: 확정 10팀(1~10위) → 결선 통과 팀은 11위, 12위.
2. 순위 배지 노출 조건을 넓혀, 확정 팀과 결선 통과 팀 모두 순위가 보이게 합니다(득표 0표인 글은 지금처럼 배지 없음). 선발 정원(12) 안에 든 팀은 모두 순위 표시.
3. "이전 라운드 확정" 배지와 "선발" 배지, 득표수 표기는 그대로 유지합니다.
4. 1라운드만 진행한 게시판(결선 없음)은 지금 동작 그대로입니다.
5. **3라운드 이상 투표 안전장치**: 확정 팀이 서로 다른 라운드에서 뽑혔을 때, 득표수를 비교하는 기준(`lockedCountOf`)이 "가장 최근에 표를 받은 라운드"가 되어 섞여 보이는 문제를 막습니다. 현재는 1~2라운드만 사용하지만, 확정 팀은 해당 라운드의 득표수를 그대로 표시하고, 순위 매기기는 **라운드별로 그룹을 나눠** 수행합니다(같은 라운드끼리만 경쟁 순위, 다음 라운드 그룹은 이전 그룹 전체 순위 뒤에서 이어 받음). 이 코드는 2라운드에서도 확정 팀이 동일 라운드(1라운드)이므로 기존처럼 1~10위, 이어 11~12위로 나옵니다.
6. **동점 후보 overflow 처리**: 정원(12석) 경계에서 동점 그룹이 걸리면, `rank <= seats` 조건으로는 일부만 "선발" 배지를 받아 혼란이 생깁니다. 결선 종료 화면에서는 표시 범위를 `rank <= seats` 대신 **"결선 통과자 전체(득표 0 제외) + 1차 확정 팀 전체"**로 통일하여, 동점 그룹 전체가 같은 배지 상태를 갖게 합니다. 단일 라운드(결선 없음)에서는 기존 3위 이내 배지 조건을 유지합니다.

## 기술 세부

`src/components/VoteSection.tsx`만 수정(서버·DB 변경 없음):
- `rankMap`을 `ordered`(확정 팀 → 결선 후보 순) 기준으로 계산하되, 두 그룹을 따로 순회합니다.
  - 그룹 A(확정 팀): 득표수 = `lockedCountOf(id)`, 시작 순위 1. 3라운드 이상 확정 팀은 **라운드별 서브그룹**으로 나눠, 같은 라운드 안에서만 경쟁 순위를 매기고, 다음 라운드 그룹은 이전 그룹의 마지막 순위 + 1부터 시작합니다.
  - 그룹 B(결선 후보): 득표수 = `counts[id]`, 시작 순위 = 그룹 A의 마지막 순위 + 1.
  - 각 그룹 내부에서 표준 경쟁 순위(동점 = 같은 순위, 다음은 건너뜀)를 적용하고, 공동 순위일 때만 "공동 N위".
- 카드 렌더링에서 `rankInfo`의 확정 팀 제외 로직을 없애고, 표시 조건을 `status === "closed" && count > 0 && (showFinal ? rank <= ordered.length : rank <= 3)`으로 바꿉니다. `showFinal`이면 득표가 0이 아닌 모든 항목에 순위/배지를 표시합니다.
- `showFinal`이 아닐 때(단일 라운드)는 기존 계산·기존 표시 조건(3위 이내)을 그대로 씁니다.

## 부작용 검토

- 서버 쿼리 추가 없음(이미 받아 둔 `roundCounts`만 사용) → 비용 변화 없음.
- 선발/동점 판정(`winnerInfo`)은 손대지 않아 추가 결선 로직에 영향 없음.
- 정렬 순서 자체는 이미 확정 팀 → 결선 후보라 변경되지 않고, 배지 문구만 정확해집니다.
- 3라운드 이상 안전장치는 현재 실제 3라운드 투표가 없어 곧바로 가시적 변화는 없지만, 향후 사용 시 잘못 섞인 순위를 방지합니다.
- 결선 종료 후에는 정원 안에 든 모든 팀에 순위가 표시되므로, 동점 overflow 상황에서 배지가 일관되게 노출됩니다.

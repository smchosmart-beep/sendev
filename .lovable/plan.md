# 관련 링크를 파일 첨부 버튼 옆으로 이동

문제 정의 과정 기록 카드에서 지금은 "관련 링크" 입력칸이 텍스트 칸 영역(전체 폭)에 따로 있고, "관련 파일" 첨부는 그 아래 줄에 있습니다. 이 둘을 **한 줄**에 나란히 배치합니다.

## 화면

```text
[언제·어디서] [무엇을 나눴나요?] [그래서 정한 것]
관련 파일 (최대 3개, 개당 3MB) / 관련 링크
[파일칩][파일칩] [파일 첨부]   [ https://... 링크 입력 ]
[저장] [삭제]
```

- 왼쪽: 기존 파일 칩 + [파일 첨부] 버튼 (동작 그대로).
- 오른쪽: 관련 링크 한 줄 입력칸. 남는 폭을 채우도록 늘어나며, 좁은 화면(모바일)에서는 자동으로 아랫줄로 내려갑니다.
- 저장 시 `https://` 자동 보정 등 기존 규칙은 그대로 유지합니다.

## 기술 메모

- `src/components/RecordEditor.tsx`의 `RowItem`만 수정합니다.
  - `labels.map` 렌더링에서 `linkCol`도 `fileCol`처럼 건너뛰도록 처리.
  - 파일 첨부 블록을 `flex` 컨테이너로 감싸 왼쪽 파일 영역 / 오른쪽 링크 입력(`flex-1 min-w-[16rem]`)을 배치하고, 각각 라벨을 유지.
- 저장 로직, 링크 보정, 2900자 가드, README 출력(`record-readme.ts`)은 변경 없음.

## 부작용 점검

- 다른 섹션은 `linkCol`/`fileCol`이 없어 영향 없음. 데이터 구조·서버 함수 변경 없음.

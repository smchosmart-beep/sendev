# 상단 메뉴바 좁은 화면 깨짐 수정

## 문제

창 폭이 약 1000~1200px일 때 상단 메뉴바의 탭 글자("사용자 가이드", "캘린더" 등)가 세로로 한 글자씩 쪼개지고, 로고와 아이콘 버튼이 서로 겹쳐 보입니다. 탭 영역이 남는 공간에 맞춰 무한정 줄어들면서 글자가 강제로 줄바꿈되기 때문입니다.

## 수정 방향 (표시 전용, 기능 변경 없음)

1. 탭 링크에 줄바꿈 금지와 축소 금지 적용 — 글자가 세로로 쪼개지지 않게 합니다.
2. 화면이 좁을 때는 가이드/홈/캘린더 탭도 게시판 탭과 동일하게 아이콘만 표시하고, 넓어지면 라벨이 다시 나타나도록 단계별 기준을 통일합니다(활성 탭은 라벨 유지).
3. 로고 텍스트는 좁은 화면에서 글자 크기를 한 단계 줄이고 줄바꿈을 막습니다.
4. 그래도 공간이 부족한 구간에서는 탭 영역이 로고·우측 버튼을 밀어내지 않도록 가로 넘침을 숨기고, 필요 시 기존 "메뉴 접기" 버튼과 모바일 시트 메뉴로 자연스럽게 넘어가게 합니다.
5. 좌우 여백(px-28)이 좁은 화면에서 과도하므로 중간 구간에서는 여백을 줄여 탭 공간을 확보합니다.

## 기술 세부

- 대상 파일: `src/routes/_main.tsx` 헤더 블록(167~246행)만 수정.
- 각 탭 `Link`에 `whitespace-nowrap shrink-0` 추가.
- 라벨 표시 조건을 `hidden xl:inline` / 활성 시 `inline` 형태로 통일(게시판 탭의 기존 `2xl` 기준도 함께 조정).
- 컨테이너 패딩을 `px-6 lg:px-10 2xl:px-28`로 단계화.
- nav에 `overflow-hidden` 유지 + `min-w-0`.
- 데이터/쿼리/라우팅 로직은 손대지 않으며 미열람 배지 동작도 그대로 유지.

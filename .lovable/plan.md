## 문제ZIP 페이지 헤더 중복 제거

문제ZIP 카테고리 상세 페이지에서 상단 카드(`카테고리명 + 설명`)와 바로 아래 섹션 헤더(`📦 문제ZIP`)가 사실상 같은 정보를 반복해 세로 스크롤을 만들고 있음. 상단 카드는 카테고리 설명까지 담고 있으므로 그대로 두고, **아래쪽 섹션 h2(아이콘 + 이름)를 제거**하여 중복을 없앰. 제보 버튼과 정렬 토글은 그대로 유지.

### 변경 파일
- `src/routes/_main.board.$slug.index.tsx`
  - `category.enableProblem` 섹션에서 `<h2>` (PackageOpen + 이름) 제거
  - `flex items-center justify-between` 컨테이너는 유지하되, 왼쪽 자리를 비우고 `justify-end`로 변경 → "문제 제보하기" 버튼만 우측 정렬
  - 정렬 토글(최신순/좋아요순) 그대로 유지
  - 다른 게시판 유형(일반/링크/프로젝트/질문)의 섹션 헤더는 변경하지 않음 — 그 페이지들은 여러 섹션이 공존할 수 있어 h2가 필요함

### 부작용 검토
- 다른 게시판 유형에는 영향 없음 (분기 내부만 수정).
- 로직/쿼리/서버 함수 변경 없음 — 순수 UI 정리.
- 가이드 문서 업데이트 불필요 (기능 변화 없음, 시각 배치만 조정).

# 문제ZIP Q1 "영역" 직접 입력 허용

현재 Q1(고통받는 영역)은 관리자가 등록한 버튼 목록에서 **단일 선택만** 가능합니다. 여기에 **"직접 입력"** 옵션을 추가해, 목록에 없는 영역도 사용자가 자유롭게 적을 수 있도록 합니다.

## 대상 파일
`src/routes/_main.board.$slug.new-problem.tsx` (프론트엔드만 수정)

## 변경 내용

1. **"기타(직접 입력)" 버튼 추가**
   - Q1 버튼 목록 마지막에 `➕ 직접 입력` 버튼을 추가합니다.
   - 이 버튼을 선택하면 바로 아래에 텍스트 입력창이 나타납니다.

2. **직접 입력창**
   - `➕ 직접 입력`이 선택된 상태에서만 노출되는 `Input`.
   - placeholder: "고통받는 영역을 직접 입력해주세요"
   - 최대 길이 20자 정도로 제한.
   - 기존 버튼(💊보건/건강 등)을 다시 누르면 직접 입력창은 사라지고 그 값으로 대체됩니다.

3. **제출 로직**
   - 직접 입력 모드일 때: 입력창의 값을 `problemArea`로 전송(공백이면 "고통받는 영역을 입력해주세요" 토스트).
   - 버튼 선택 모드일 때: 기존과 동일하게 선택한 버튼 라벨을 전송.
   - 서버(`createPost`)는 이미 `problemArea`를 자유 문자열로 저장하므로 **백엔드 변경 없음**.

## 동작 정리
- 버튼 선택 ↔ 직접 입력은 상호 배타적(하나의 `area` 값으로 귀결).
- 목록/상세에서 표시되는 방식은 기존과 동일 — 저장된 문자열이 그대로 뱃지/텍스트로 노출됩니다.

## 가이드 업데이트
`src/routes/_main.guide.tsx`의 문제ZIP 설명에 "Q1 영역은 직접 입력도 가능" 한 줄 반영.

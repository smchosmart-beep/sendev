게시판 상단 카테고리 정보 카드의 수직 공간을 줄입니다.

## 변경 범위
- `src/routes/_main.board.$slug.tsx` 내 카테고리 제목/설명 카드

## 변경 내용
- 카드 패딩을 `p-6` → `p-4`로 줄입니다.
- 제목 크기를 `text-2xl` → `text-xl`로 줄입니다.
- 설명 문구는 **실제 설명이 있을 때만** 표시하고, `설명이 없습니다.`라는 placeholder는 제거하여 빈 공간을 없앱니다.
- 설명이 있을 때만 제목과 설명 간격을 최소한(`mt-0.5`)으로 유지합니다.

## 부작용 검토
- 해당 카드는 게시판 하위 모든 페이지 목록 상단에 공통으로 노출되므로, 모든 게시판의 상단 여백이 일관되게 줄어듭니다.
- 다른 기능(비밀번호 게이트, Outlet, 뒤로가기 링크)에는 영향이 없습니다.
- 데이터/DB/서버 호출 변경 없음, 순수 UI 레이아웃 수정입니다.
- 사용자 가이드에는 별도 업데이트가 필요 없습니다(기능 변경이 아닌 시각적 여백 조정).

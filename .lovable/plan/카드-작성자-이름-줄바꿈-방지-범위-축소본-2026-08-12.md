# 카드 작성자 이름 줄바꿈 방지 (범위 축소본)

이전 조치(마우스 오버 시 전체 이름 표시)는 표시만 보완했을 뿐, "김승 / 현"처럼 이름이 두 줄로 쪼개지는 현상은 그대로입니다. 레이아웃 자체를 고칩니다.

## 확인된 현재 상태

- 공지 카드·일반글 카드: 이미 한 줄 유지 처리가 되어 있어 **변경하지 않습니다.**
- 문제ZIP 카드: 작성자 이름 텍스트를 아예 표시하지 않아 **변경 대상이 아닙니다.**
- 실제 문제 지점은 **링크 카드(해커톤 사례집 등)와 프로젝트 카드** 두 곳입니다.

## 원인

작성자 줄이 `이름 + 레벨/역할 배지 + 조회수`를 한 줄 flex로 묶었는데, 카드 폭이 좁으면 배지가 공간을 차지해 이름이 글자 단위로 줄바꿈됩니다.

## 변경 내용

`src/routes/_main.board.$slug.index.tsx`의 링크 카드·프로젝트 카드 작성자 줄에만 적용:

- 작성자 줄 컨테이너와 이름 영역에 `min-w-0`을 주어 텍스트가 줄어들 수 있게 함
- 이름은 한 줄 유지 + 넘치면 말줄임 (`truncate`)
- 사람 아이콘, 레벨/역할 배지, 조회수는 `shrink-0`으로 고정해 찌그러지지 않게 함
- 기존 `title` 속성 유지 (마우스 오버로 전체 닉네임 확인)

## 범위 밖

데이터·쿼리·권한·서버 로직은 전혀 변경하지 않으며, 두 컴포넌트의 CSS 클래스만 조정합니다.

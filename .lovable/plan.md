## 현재 상황 정리

테스트로 렌더링 단계(마크다운→HTML→정화)를 직접 돌려본 결과, `<span style="color: ...">`는 정화 과정에서 **그대로 유지**됩니다. 즉 저장된 본문에 색상 span만 들어 있으면 색은 정상 표시됩니다. 그래서 남은 문제는 두 가지입니다.

1. **글자 색이 안 보임** — 가장 유력한 원인: 직전 색상 직렬화 수정이 아직 **게시(Publish)되지 않아** 공개 사이트(sendev.kr)에는 반영되지 않음. 공개 사이트의 옛 코드로 다시 저장하면 색 정보가 또 사라짐.
2. **줄바꿈 후 한 줄 띄우기(빈 줄)가 사라짐** — 마크다운으로 저장할 때 빈 문단이 직렬화 과정에서 버려져 빈 줄이 합쳐짐. (별개의 기존 버그)

## 해결

### A. 글자 색 (검증 + 게시)
- 먼저 **미리보기(preview)** 에서 색상 지정 → 저장 → 상세 페이지에서 색이 유지되는지 확인.
  - 미리보기에서 정상이면 코드 수정은 완료된 상태이므로 **게시**만 하면 공개 사이트에도 적용됨.
  - 미리보기에서도 안 되면 직렬화 로직을 추가 점검/보정.

### B. 빈 줄(한 줄 띄우기) 보존
`src/components/PostEditor.tsx`에서 빈 문단이 저장 시 사라지지 않도록 처리합니다.
- 에디터의 마크다운 직렬화에서 **빈 문단을 빈 줄로 보존**되게 만듭니다. 구체적으로 빈 문단을 비가시 문자(`&nbsp;` 한 칸)나 명시적 빈 줄 마커로 직렬화하여, 다시 불러오거나 렌더링할 때 한 줄 간격이 유지되도록 합니다.
- 상세 페이지 렌더링(`_main.board.$slug.$postNo.tsx`)에서 빈 문단/공백 문단이 적절한 높이로 표시되는지 확인하고, 필요하면 빈 문단에 최소 높이를 부여.

## 검증
- 색: 미리보기에서 빨강/파랑 등 지정 후 저장 → 상세에서 색 유지 확인.
- 빈 줄: 문단 사이 빈 줄을 넣어 저장 → 상세에서 빈 줄 간격 유지 확인.
- 기존 글이 깨지지 않는지 확인.
- 확인 후 **게시**.

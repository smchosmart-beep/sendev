## 목표

관리자 게시판 목록에서 "수정" 버튼을 눌렀을 때, 그 게시판에 저장된 입장 비밀번호가 모달에 채워져 보이도록 한다. 지금은 항상 빈칸이라 비밀번호가 있는지 알 수 없다.

## 현재 동작과 원인

- 보안상 게시판 목록 데이터(`listCategories`)는 실제 비밀번호를 클라이언트로 보내지 않고 `hasPassword`(있음/없음) 값만 전달한다.
- 그래서 수정 모달은 항상 비밀번호 입력란을 빈 값으로 시작한다 (`admin.categories.tsx`의 `openEdit`에서 `setEditPassword("")`).

## 변경 내용

### 1. 비밀번호 조회용 관리자 서버 함수 추가 — `src/lib/platform.functions.ts`
- 단일 게시판의 비밀번호만 돌려주는 새 서버 함수 `getCategoryPassword`(POST, 입력: 게시판 id)를 추가한다.
- 서비스 롤 관리자 클라이언트로 해당 게시판의 `password`만 조회해 `{ password: string }` 형태로 반환한다.
- 전체 목록(`listCategories`)에는 비밀번호를 계속 노출하지 않아, 공개 게시판 목록의 보안 성격을 유지한다.

### 2. 수정 모달 열 때 비밀번호 불러오기 — `src/routes/admin.categories.tsx`
- `openEdit(c)`에서 모달을 열면서 `getCategoryPassword`를 호출해 받아온 값을 `editPassword`에 채운다.
- 불러오는 동안에는 입력란을 일시적으로 비워두거나 로딩 표시를 하고, 응답이 오면 채운다.
- 사용자가 비밀번호를 비우고 저장하면 비밀번호 없는(공개) 게시판이 되도록 기존 저장 로직과 일관되게 동작시킨다.

## 참고
- 보안 관점에서 이 비밀번호는 관리자 페이지에서만 조회되며, 전체 목록 API에는 여전히 노출되지 않는다.

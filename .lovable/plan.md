## 요약
사용자 가이드 페이지의 "레벨(LV) 제도"와 "배지 제도" 섹션에, 레벨과 배지가 실제 UI에서 어디에 어떻게 표시되며 배지가 여러 개일 때 어떻게 축약/확장되는지 설명 문구를 추가한다.

## 상세

### 1. 레벨(LV) 제도 섹션에 표시 위치 설명 추가
- 내 페이지 상단 카드에 "Lv.N" 형태로 표시된다는 설명 추가.
- 게시글/댓글 목록의 작성자 닉네임 옆에도 "Lv.N" 뱃지가 표시된다는 설명 추가.

### 2. 배지 제도 섹션에 표시 위치 및 다중 배지 표현 설명 추가
- 내 페이지에서는 보유한 모든 배지가 아이콘과 이름으로 나열되어 표시됨.
- 게시글/댓글의 작성자 이름 옆에는 첫 번째 배지 아이콘만 표시되고, 나머지 배지는 "+N" 형태로 축약 표시됨.
- "+N"을 클릭(또는 탭)하면 팝오버로 전체 보유 배지 목록이 펼쳐져 보임.
- 닉네임을 변경해도 보유 배지는 그대로 유지됨(기존 문구 유지).

### 변경 대상 파일
- `src/routes/_main.guide.tsx` — 두 섹션의 children 텍스트 영역에 문구 추가.

# 포스트잇 색상 톤 통일

## 목표
플랫폼의 핵심 색조(민트/에메랄드, hue 162 + 쿨 계열)에 어울리도록 포스트잇 팔레트를 채도 낮은 파스텔로 재조정한다. 색 "이름"(yellow, pink, green, blue, purple, orange)은 그대로 두고 실제 값만 바꿔, 컴포넌트 코드(`COLOR_BG` 매핑)는 수정하지 않는다.

## 변경 대상
`src/styles.css` 의 두 블록만 수정:
- `:root` (라이트) 109~116행: `--postit-*` 6색 + foreground
- `.dark` 153~160행: `--postit-*` 6색 + foreground

`src/components/HackathonReviews.tsx` 는 변경하지 않음 (토큰 이름 유지).

## 새 팔레트 방향 (라이트 기준)
플랫폼 민트 톤을 중심에 두고, 주변 색을 모두 채도를 낮춰(약 chroma 0.04~0.06) 부드러운 파스텔 카드 느낌으로 통일. 명도는 0.92~0.95로 비슷하게 맞춰 한 세트처럼 보이게 함.

```text
yellow → 크림 아이보리   (따뜻한 중성, 낮은 채도)
green  → 라이트 민트      (플랫폼 primary 계열, 중심색)
blue   → 스카이/세이지 블루(쿨, 낮은 채도)
purple → 라벤더 그레이    (채도 크게 낮춤)
pink   → 더스티 로즈      (채도 낮춤)
orange → 소프트 피치      (채도 낮춤)
```

전체적으로 노랑의 형광기(현재 oklch 0.94 0.1 100)를 제거하고, 민트(hue 162) 톤을 한 자리 추가해 플랫폼과 시각적 연속성을 확보.

## 다크 모드
동일한 색상 계열을 유지하되 명도를 낮추고(0.82~0.86) 다크 배경에서 글자(`--postit-foreground`)가 읽히도록 대비를 유지. 라이트와 같은 hue를 사용해 일관성 유지.

# 닉네임 도용 방지 (닉네임 + 비밀번호)

## 목표
현재는 글/댓글 작성 시 작성자명이 자유 입력이라 누구나 남의 닉네임을 그대로 쳐서 같은 이름·레벨·뱃지로 글을 쓸 수 있습니다. 회원가입 없이, **닉네임을 처음 쓸 때 비밀번호를 정하고 이후 같은 닉네임으로 글·댓글을 쓰려면 그 비밀번호를 입력**하도록 만들어 도용을 막습니다.

## 동작 방식

```text
작성자명 입력 + 닉네임 비밀번호 입력
        │
        ▼
이 닉네임이 이미 등록되어 있나?
   ├─ 아니오 → 비밀번호와 함께 닉네임을 "등록(선점)" 하고 작성 진행
   └─ 예    → 입력한 비밀번호가 등록된 비밀번호와 일치?
                 ├─ 일치  → 작성 진행
                 └─ 불일치 → "이미 사용 중인 닉네임입니다. 비밀번호가 일치하지 않습니다." 거부
```

- 빈 작성자명 / "익명" / 공지(운영진) 글은 이 검사를 건너뜁니다.
- 닉네임 비밀번호는 글 수정용 비밀번호(`edit_password`)와는 별개입니다.

## 변경 사항

### 1. 데이터베이스 (마이그레이션)
- `user_profiles` 테이블에 닉네임 비밀번호 보관 컬럼 추가
  - `nickname_password` (text, 기본값 빈 문자열) — 평문이 아닌 **해시값**으로 저장
  - `claimed_at` (timestamptz, nullable) — 선점 시각
- 기존 행(이미 등록된 닉네임)은 비밀번호가 비어 있는 상태 → 다음에 그 닉네임으로 처음 글 쓰는 사람이 비밀번호를 정하게 됨.

### 2. 서버 로직 (`src/lib/platform.functions.ts`)
- 닉네임 비밀번호를 SHA-256으로 해시하는 헬퍼 추가 (Web Crypto, 서버 전용 — 평문은 저장/반환하지 않음).
- `ensureNicknameOwnership(db, author, nicknamePassword, isNotice)` 헬퍼 추가:
  - 검사 제외 조건(빈 이름/익명/공지) 처리
  - 등록된 닉네임이면 비밀번호 일치 검증, 없으면 비밀번호와 함께 선점 등록 (비밀번호 최소 길이 검증)
- `createPost`, `createComment` 입력 스키마에 `nicknamePassword` 추가하고, insert 전에 위 헬퍼 호출.
- 관리자용 함수 추가: 특정 닉네임의 비밀번호 초기화(분실 대응) → `resetNicknamePassword`.
- 어떤 서버 함수도 닉네임 비밀번호 원문/해시를 클라이언트로 반환하지 않음.

### 3. 작성 폼 UI (프론트엔드)
다음 폼에 "닉네임 비밀번호" 입력 칸 추가 (작성자명 칸 바로 아래, 안내 문구 포함: "이 닉네임을 처음 쓰면 비밀번호가 등록되고, 다음부터 같은 비밀번호로 인증합니다.")
- `_main.board.$slug.new-general.tsx`
- `_main.board.$slug.new-question.tsx`
- `_main.board.$slug.new-project.tsx`
- `_main.board.$slug.new-link.tsx`
- `_main.board.$slug.$postNo.tsx` (댓글 작성 영역)

각 폼에서 `nicknamePassword` 상태를 추가하고 서버 호출 시 전달. 비밀번호 불일치 시 서버 에러 메시지를 토스트로 노출.

### 4. 관리자 화면 (`src/routes/admin.profiles.tsx`)
- 사용자 프로필 목록 각 행에 "비밀번호 초기화" 버튼 추가 (분실 시 재선점 허용). 잠금 게이트 안쪽이라 이미 보호됨.

## 참고 (기술 세부)
- 공지 글은 작성자가 "운영진"으로 고정되므로 닉네임 검사 대상에서 제외합니다.
- `user_profiles`는 `username_key`(소문자 정규화)로 매칭하므로 대소문자/공백 차이로 인한 우회를 막습니다.
- 해시 저장으로 DB가 노출되어도 비밀번호 원문이 드러나지 않습니다.
- 기존 데이터 호환: 이미 글을 쓴 닉네임도 비밀번호가 비어 있으면 다음 작성자가 선점하게 되는데, 이미 활동 중인 본인이 먼저 비밀번호를 정할 수 있도록 안내 문구로 유도합니다.

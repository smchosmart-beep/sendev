# 배지 표시: 여백이 있으면 전부 펼치기

작성자 배지가 항상 "대표 배지 + +N" 형태로 접혀 있는데, 배지 줄이 독립된 행으로 분리된 카드에서는 가로 여백이 남아도 접혀 보입니다. 여백이 있을 때는 모든 배지를 펼쳐 보여주도록 바꿉니다.

## 동작

- 배지 행에 공간이 충분하면 보유 배지를 전부 나란히 표시합니다.
- 폭이 부족하면 지금처럼 대표 배지 1개 + `+N` 칩으로 접히고, 클릭하면 전체 목록 팝오버가 뜹니다.
- 접힘/펼침 판단은 실제 렌더 폭 기준으로 자동 처리하므로 PC·모바일 모두 자연스럽게 동작합니다.

## 기술 사항

- `src/components/AuthorBadge.tsx`
  - 배지 컨테이너에 `ResizeObserver`(+ 초기 1회 측정)를 붙여 사용 가능한 폭과 펼친 배지들의 실제 폭을 비교.
  - 상태 `expanded`(기본 false)로 시작해 측정 후 들어가면 전체 배지 렌더, 넘치면 기존 `+N` 접힘 렌더 유지.
  - 측정 시 레이아웃 깜빡임을 줄이기 위해 `useLayoutEffect` 사용, 폭 변화가 임계치 이상일 때만 상태 갱신(무한 루프 방지).
  - 팝오버·아이콘·`only`(level/awards/all) 등 기존 API와 스타일은 그대로 유지 → 다른 사용처(게시글 상세, 댓글, 목록 카드)에 영향 없음.

## 검증

- 해커톤 사례집 카드(넓은 폭): 배지 2개가 모두 한 줄에 표시되는지 확인.
- 좁은 카드/모바일: `+N` 접힘과 팝오버가 그대로 동작하는지 확인.

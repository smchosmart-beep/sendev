## 문제

`StarRating`의 각 별이 고정 크기(`h-8 w-8`, 32px)라 만점이 10점이면 별 10개 + 오른쪽 점수 텍스트가 모바일 화면 폭을 넘어 잘립니다(이미지 참고).

## 해결

별을 고정 크기 대신 **컨테이너 폭에 맞춰 줄어드는 반응형**으로 바꿉니다. 별 5개 이하일 때는 기존 32px를 유지하고, 5개를 초과하면 가용 폭을 균등 분배해 화면 안에 들어오게 합니다.

`src/routes/_main.board.$slug.$postNo.tsx`의 `StarRating` 컴포넌트만 수정합니다.

1. 바깥 래퍼(944행 `flex items-center gap-3`):
   - 별 영역(별들을 감싼 `div`, 945행)에 `min-w-0 flex-1` 추가 → 폭을 채우되 점수 텍스트를 밀어내지 않음.
   - 점수 텍스트 `span`(991행)에 `shrink-0` 추가 → 점수는 줄바꿈/잘림 없이 유지.

2. 각 별 셀(979행 `relative inline-block h-8 w-8`):
   - `h-8 w-8` → `aspect-square w-full max-w-8 flex-1`로 변경. 별 개수가 적으면 `max-w-8`(32px)에서 멈추고, 많으면 `flex-1`로 균등 축소.

3. 내부 `Star` 아이콘 두 곳(980, 985행)의 `h-8 w-8` → `h-full w-full`로 변경해 셀 크기를 따라가게 함.

별 위치 기반 점수 계산(`valueFromClientX`)은 컨테이너 `rect.width` 비율을 쓰므로 크기가 바뀌어도 그대로 동작합니다. 다른 로직 변경은 없습니다.

투표 게시판 카드 본문의 줄바꿈 표시(\) 제거

## 목표
투표 게시판 목록 카드에 본문 요약을 표시할 때, 콘텐츠에 포함된 줄바꿈 이스케이프 문자(예: `\n`, `\[...\]` 등)가 그대로 노출되어 지저분해 보이는 문제를 해결한다. 카드에는 깔끔한 평문만 남도록 한다.

## 수정 범위
1. `src/lib/post-text.ts`의 `htmlToPlainText` 또는 `voteCardText` 함수에 이스케이프 문자 정리 로직 추가
   - HTML 태그 제거 후 남은 리터럴 `\n`을 공백으로 치환
   - 마크다운/템플릿용 리터럴 백슬래시(`\[`, `\]`)는 제거하되, 본문의 의미 있는 다른 백슬래시는 보존하지 않음
2. `src/components/VoteSection.tsx`의 카드 본문 `<p>`에서 `whitespace-pre-line` 사용 여부 재확인: 평문만 남기면 `whitespace-pre-line`이 필요하지 않을 수 있음

## 검증
- 타입체크(`bunx tsc --noEmit`) 통과
- 투표 게시판 미리보기에서 카드 본문에 백슬래시가 남아 있지 않은지 확인
- 투표 종료 전/후 카드 모두 동일하게 적용되는지 확인

## 영향
- 표시 로직만 변경하며 DB 스키마, 서버 권한, 투표 기능에는 영향이 없다.
- 투표 본문 상세 페이지의 본문 렌더링은 별도로 두고, 카드 요약 텍스트만 정리한다.

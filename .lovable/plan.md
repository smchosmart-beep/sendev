# 활동기록 메뉴명 변경 및 사례집 출력 메뉴 추가

## 요약
- `07 출력보기` 메뉴명을 `07 README 출력`으로 변경합니다.
- `08 사례집 출력` 메뉴를 추가하되, 세부 기능은 추후 구현하고 지금은 준비중 placeholder로 표시합니다.
- 사용자 가이드의 관련 설명을 함께 업데이트합니다.

## 변경 대상 및 상세

### 1. `src/components/RecordEditor.tsx`
- 상단 `STEPS` 배열에서 마지막 항목을 아래와 같이 변경·추가합니다.
  ```text
  07 → "README 출력"
  08 → "사례집 출력" (신규)
  ```
- `step === 6`에 렌더링되는 기존 `RecordOutput` 컴포넌트는 그대로 둡니다(README 출력).
- `step === 7`에 새로운 placeholder 섹션을 추가합니다. 내용은 제목과 "이 기능은 추후 준비될 예정입니다" 안내 문구만 표시합니다.
- 하단 이전/다음 단계 버튼의 범위는 `STEPS.length`에 따라 자동으로 확장됩니다.

### 2. `src/components/RecordOutput.tsx`
- 컴포넌트 내부 섹션 제목을 `출력 보기`에서 `README 출력`으로 변경합니다.
- README 구성 / 최종 README 탭과 기능은 그대로 유지합니다.

### 3. `src/routes/_main.guide.tsx`
- 활동기록 단계 설명에서 `07 출력 보기`를 `07 README 출력`으로 일괄 변경합니다.
- "활동기록 – 출력 보기(README 미리보기·인쇄)" 섹션 제목을 "활동기록 – README 출력"으로 변경합니다.
- `08 사례집 출력`이 추가되었음을 간단히 안내하는 문구를 추가합니다(예: "08 사례집 출력은 추후에 제공할 예정입니다").

## 고려 사항
- `RecordOutput`의 `onGoStep` prop이나 블록 이동 로직은 변경하지 않습니다.
- `src/lib/record-readme.ts`의 `getPublicReadmeBlocks` 10개 블록 구성과 단계 매핑은 그대로 유지합니다(README 출력 기능이므로).
- 사례집 출력은 세부 구현이 없으므로 빈 상태/준비중 UI만 노출되어 사용자가 혼란스럽지 않도록 합니다.

## 검증 항목
- TanStack Start 타입체크가 통과하는지 확인합니다.
- 활동기록 에디터에서 상단 단계 버튼에 8개 단계가 정상 표시되는지 확인합니다.
- 07 단계 클릭 시 기존 README 출력 기능이 정상 동작하는지 확인합니다.
- 08 단계 클릭 시 placeholder 문구만 보이는지 확인합니다.
- 사용자 가이드에서 활동기록 단계 문구가 업데이트되었는지 확인합니다.

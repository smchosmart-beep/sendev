# 활동기록 "문제 정의 과정" 모바일 드롭박스 개선

## 목표
활동기록의 **02 문제 정의 과정** 단계에서, 기록 종류(탭)를 선택하는 UI를 **모바일에서는 드롭박스(셀렉트)**, **PC에서는 기존 탭 버튼** 형태로 각각 표시한다. 현재 모바일에서는 탭 버튼이 세로로 길게 늘어져 사용성이 떨어지는 문제를 해결한다.

## 변경 범위
- `src/components/RecordEditor.tsx` — `RowSection` 컴포넌트의 탭 선택 영역을 반응형으로 분기
- `src/routes/_main.guide.tsx` — 02 문제 정의 과정 설명에 모바일 드롭박스 UI 언급 추가

## 구현 상세

### 1. 탭 선택 UI 반응형 분기 (`RowSection`)
- 기존 탭 버튼 영역(`subtypes.map(...)`)은 **PC(`sm:` 이상)**에서만 표시한다.
- **모바일(`sm:` 미만)**에서는 `src/components/ui/select.tsx`(shadcn Select)를 사용해 드롭박스를 렌더링한다.
- 드롭박스는 **02 문제 정의 과정(`def.kind === "process"`)에만 적용**한다. `RowSection`이 공통 컴포넌트이므로, `AI_USE_TYPES` 등 다른 탭은 기존 탭 버튼 UI를 그대로 유지한다.
- 드롭박스 구성:
  - 트리거 문구: "기록 종류 선택"
  - 옵션: `22일 팀빌딩·문제 정의 회의`, `인터뷰 기록`, `인터뷰 후 문제 구체화 회의`, `그 밖의 문제 정의 메모`
- 선택 상태는 기존 `selectedSubtype` 상태를 그대로 사용하여 탭/드롭박스 간 전환 시에도 값이 동기화된다.
- 드롭박스 변경 시 `setSelectedSubtype(value)`로 동일하게 동작한다.

### 2. 사용자 가이드 갱신
- `src/routes/_main.guide.tsx`의 "02 문제 정의 과정" 문단에서, 모바일에서는 기록 종류를 **드롭박스 메뉴**로 고르고, PC에서는 탭 버튼으로 고른다는 내용을 추가한다.
- 기존 설명(탭별 양식, 이미지 첨부, 유튜브 링크, 저장 방식 등)은 그대로 유지한다.

## 검증
- 모바일 프리뷰(예: 375px)에서 드롭박스가 나타나고, 4개 옵션 중 선택 시 해당 양식/기록이 정상적으로 표시되는지 확인한다.
- PC 프리뷰에서 기존 탭 버튼이 그대로 유지되고, 선택/양식 전환이 정상 동작하는지 확인한다.
- 가이드 페이지에서 "02 문제 정의 과정" 항목에 모바일 드롭박스 관련 문구가 추가되었는지 확인한다.

# 이름 기반 중복 평가 방지 (이름 비공개)

같은 게시물에 같은 이름으로 두 번 평가하지 못하게 막되, 다시 제출하면 기존 점수를 덮어씁니다. 평가자 이름은 프론트엔드 어디에도 표시되지 않고, 오직 서버에서 같은 사람인지 식별하는 용도로만 사용됩니다.

## 동작
- 평가 폼에 **이름 입력칸**(필수) 추가
- 같은 게시물 + 같은 이름 → 이전 평가를 새 점수로 **덮어쓰기**
- 이름은 평가 요약·목록 등 화면 어디에도 노출 안 함 (현재도 노출 안 됨, 그대로 유지)

## 변경 사항

### 1. 데이터베이스
- `reviews` 테이블에 `(post_id, reviewer_name)` 고유 제약 추가
- 기존에 이름이 빈 값인 평가가 있으면 제약 추가 실패 가능 → 마이그레이션 전 빈 이름 데이터 정리 필요

### 2. 서버 함수 (`src/lib/platform.functions.ts`)
- `createReview`에서 `reviewerName` 필수 검증(빈 문자열 거부)
- `insert` → `(post_id, reviewer_name)` 기준 **upsert**로 변경 (같은 이름이면 점수 교체)

### 3. UI (`src/routes/_main.board.$slug.$postNo.tsx`)
- 평가 폼에 이름 입력 필드 추가
- 신규 제출 / 갱신 제출에 따라 안내 메시지 구분 (예: "평가가 갱신되었어요")
- 이름은 입력 폼에서만 받고, 결과 화면에는 절대 표시하지 않음

## 한계
이름 기반이라 다른 이름을 쓰면 우회 가능합니다. 완전 차단은 추후 로그인 도입이 필요합니다.

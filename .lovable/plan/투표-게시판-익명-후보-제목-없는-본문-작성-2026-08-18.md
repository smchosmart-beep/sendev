# 투표 게시판: 익명 후보 + 제목 없는 본문 작성

## 목표
1. 투표 종료 전까지 후보 글의 작성자 이름을 감춘다 (익명 처리).
2. 투표 게시판 글 등록 시 제목·대표 링크 입력칸을 없애고 본문만 작성한다.
3. 제목이 사라지므로 목록 카드에는 본문 내용이 보이도록 한다.

## 1) 작성자 숨김
- 후보 카드(투표 목록)와 게시글 상세 화면에서 `type === "vote"` 이고 투표 상태가 `closed`가 아니면 작성자 이름 대신 `익명`으로 표시.
- 투표 종료(`closed`) 후에는 지금처럼 실명(닉네임) 표시.
- 관리자(관리자 비밀번호 보유)에게는 종료 전에도 작성자를 보여줌(운영·중복 확인 목적).
- 우회 경로 차단:
  - 전역 검색: 서버 `searchPosts`가 결과를 만들 때, 투표가 종료되지 않은 카테고리의 `vote` 글은 작성자 값을 비워서 반환하고 화면에는 "익명"으로 표시.
  - 게시판 내 검색: 투표 글은 작성자 매칭 대상에서 제외(본문·제목으로만 검색).
- 표시만 감추는 것이며 저장된 데이터·1인 1글 검증·수정 권한 로직은 그대로 유지.

## 2) 글 등록 폼 간소화
- `new-vote` 폼에서 "제목", "대표 링크(선택)" 입력 필드 제거. 남는 항목: 내용(에디터), 작성자, 닉네임 비밀번호(+확인).
- 제출 검증: 본문과 작성자만 필수.
- 서버는 제목을 필수(1자 이상)로 받으므로, 본문 텍스트의 앞부분(HTML 태그 제거 후 최대 60자)을 제목으로 자동 생성해 함께 전송. 본문이 비면 `(제목 없음)`으로 대체. 사용자에게는 노출되지 않음.
- 상세 화면의 수정 다이얼로그도 투표 글에 한해 제목·대표 링크 칸을 숨기고 본문만 수정(저장 시 제목을 동일 규칙으로 재생성해 전송 → 서버의 제목 필수 제약 충족).

## 3) 목록 카드에 본문 노출
- 투표 후보 카드에서 제목 대신 본문을 표시: HTML을 평문으로 변환해 4~5줄로 말줄임(`line-clamp`).
- 본문이 비어 있는 기존 후보 글은 저장된 제목을 대신 표시(폴백)하여 빈 카드가 생기지 않게 함.
- 순위 배지, 표 수/비공개 표시, 투표 버튼 배치는 그대로 유지.
- 상세 화면도 투표 글이면 제목 헤딩 대신 본문을 주 내용으로 표시(본문 없으면 제목 표시).

## 기술 메모
- 변경 파일: `src/routes/_main.board.$slug.new-vote.tsx`, `src/components/VoteSection.tsx`, `src/routes/_main.board.$slug.$postNo.tsx`, `src/routes/_main.board.$slug.index.tsx`(검색 필터), `src/lib/platform.functions.ts`(`searchPosts` 마스킹), 평문 변환 헬퍼 추가.
- DB 스키마 변경 없음(제목 컬럼은 자동 생성값 저장), 서버 함수 시그니처 변경 없음 → 다른 게시판 유형 영향 없음.
- `searchPosts` 마스킹은 이미 조회하는 카테고리 정보로 판단하며 추가 왕복 요청은 최소화(카테고리 상태 1회 조회).
- 투표 상태는 상세 화면에서도 `voteStateQueryOptions`/`category.voteStatus`로 확인.


## 가이드 갱신
- `/guide`의 투표 게시판 설명에 "제목 없이 본문만 작성", "투표 종료 전까지 작성자 익명" 내용을 반영.

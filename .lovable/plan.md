# 팀빌딩 탭에 템플릿 안내 블록 추가

02 문제 정의 과정 → [22일 팀빌딩·문제 정의 회의] 탭에서, **페르소나 이미지 첨부 영역 바로 위**와 **고객 여정 맵 이미지 첨부 영역 바로 위**에 읽기 전용 안내 블록을 넣습니다. 입력은 받지 않고 보여주기만 하며, 오른쪽 위에 [복사] 버튼이 있어 템플릿 텍스트를 클립보드로 복사할 수 있습니다.

## 보이는 모습

- 어두운 배경 카드, 왼쪽 위에 청록색 라벨(`템플릿 · 페르소나` / `템플릿 · 고객 여정 맵`), 오른쪽 위에 [복사] 버튼
- 본문은 고정폭 글꼴의 여러 줄 텍스트

### 템플릿 · 페르소나 (스크린샷 그대로)

```text
[기본 정보]
- 이름:
- 나이 / 신분:
- 한 줄 소개:
- 하루 일과 (문제 상황과 관련된 부분 위주):

[문제 프레임 - 4가지 질문]
- When : 언제 이 문제가 발생하나요?
- What : 구체적으로 무엇이 문제인가요?
- Why : 왜 아직 해결되지 않았나요? (그 사람은 지금 어떻게 버티고 있나요?)
- Impact : 이 문제가 해결되면 이 사람의 하루가 어떻게 달라지나요?
```

### 템플릿 · 고객 여정 맵 (초안 — 문구 주시면 그대로 교체)

```text
[여정 단계]
- 1단계 인지 :
- 2단계 시도 :
- 3단계 문제 발생 :
- 4단계 대처 :
- 5단계 결과 :

[각 단계마다 적을 것]
- 행동 : 무엇을 하나요?
- 생각 : 무슨 생각을 하나요?
- 감정 : 어떤 기분인가요? (그래프로 표시)
- 페인 포인트 : 가장 불편한 지점은?
```

## 동작

- 안내 블록은 이 탭에서만 보입니다. 다른 탭·다른 단계에는 나타나지 않습니다.
- 저장되는 데이터가 아니므로 README 출력·사례집 출력·작성 현황에는 영향이 없습니다.
- 편집 권한이 없는 사람에게도 동일하게 보입니다(읽기 전용 안내).

## 기술 메모

- 새 컴포넌트 `src/components/record/TemplateNotice.tsx`: `label`, `text` props를 받아 카드 + 복사 버튼 렌더링. 복사는 `navigator.clipboard.writeText` + 실패 시 폴백, 완료 시 sonner 토스트.
- 템플릿 문자열은 `src/lib/record-schema.ts`에 `PROCESS_TEMPLATE_NOTICES: Record<subtype, Record<colIndex, { label, text }>>` 형태로 상수 추가 — 팀빌딩 탭의 4번 열(페르소나)·5번 열(고객 여정 맵)에 매핑.
- `src/components/RecordEditor.tsx`의 `RowItem`에서 `fileCols.map(...)` 렌더링 시 해당 열에 매핑된 안내가 있으면 라벨 위에 `<TemplateNotice />`를 출력. 기존 첨부/드롭존 로직은 그대로.
- 색상은 하드코딩 대신 기존 디자인 토큰 사용.
- `src/routes/_main.guide.tsx`의 02 문제 정의 과정 설명에 "팀빌딩 탭에는 페르소나·고객 여정 맵 작성 템플릿 안내가 표시되며 복사 버튼으로 가져다 쓸 수 있다"는 문장 추가.

## 확인

- 팀빌딩 탭에서 두 안내 블록이 각 첨부 영역 위에 보이는지
- 복사 버튼이 정상 동작하는지
- 다른 탭(인터뷰 기록 등)에는 안 보이는지, 출력물에 영향 없는지

# 상단 메뉴바 줄바뀜 방지 및 간격 조정

## 목표
- 데스크탑 화면에서 상단 메뉴바의 탭들이 줄바뀜(wrap)되지 않도록 여백과 간격을 조금 좁힌다.
- 왼쪽 끝 `SEN DEV CONNECT` 로고와 오른쪽 끝 네 개 버튼(검색/내 페이지/관리자/메뉴 접기)의 위치는 변동시키지 않는다.

## 구현 내용

### 1. 헤더 내부 간격 조정
- 파일: `src/routes/_main.tsx`
- 헤더 컨테이너의 `gap-3 sm:gap-10`은 로고/네비/우측 버튼 사이 공간을 결정한다. 줄바뀜을 막기 위해 이 간격을 살짝 줄이되, 좌우 버튼 위치가 달라지지 않도록 아래만 변경한다.
  - `sm:gap-10` → `sm:gap-6` (또는 더 작은 `sm:gap-5`)
  - `gap-3`은 모바일에서만 적용되므로 그대로 유지
- 좌우 패딩 `px-6 sm:px-28`은 로고/우측 버튼의 절대 위치를 고정하므로 **변경하지 않는다**.

### 2. 수평 메뉴(nav) 간격 및 탭 패딩 조정
- `<nav>`에 `flex-nowrap`를 명시적으로 추가해 줄바뀜을 방지한다.
- nav의 `gap-2 sm:gap-7`을 줄인다:
  - `sm:gap-7` → `sm:gap-4` (또는 `sm:gap-5`)
- 각 탭 링크의 좌우 패딩을 줄인다:
  - `px-5` → `px-3 sm:px-4` (아이콘+텍스트 간격은 그대로 유지)
- 활성 탭과 비활성 탭의 시각적 구분은 유지한다.

### 3. 탭 레이블 크기(선택)
- 여전히 줄바뀜 우려가 있을 경우, 중간 너비(~1200px)에서 탭 글자 크기를 `text-[13px]`로 살짝 줄이고, `lg:text-sm`로 복원한다. 단, 기존 `text-sm` 디자인은 최대한 유지한다.

## 영향 범위
- 변경 파일: `src/routes/_main.tsx` (스타일 값만 수정)
- 의존성: 없음
- 데이터/서버/DB: 없음
- 모바일 햄버거 메뉴: 영향 없음

## 검증
- 1288px 뷰포트에서 상단 메뉴바가 한 줄로 유지되는지 확인.
- 로고와 우측 4개 버튼의 좌우 위치가 기존과 동일한지 확인.
- 모바일에서는 햄버거 메뉴가 그대로 동작하는지 확인.

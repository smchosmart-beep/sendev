# [인터뷰 후 문제 구체화 회의] 탭 전용 양식

## 무엇을 만드나
02 문제 정의 과정에서 기록 종류를 **[인터뷰 후 문제 구체화 회의]** 로 고르면, 기존 5칸 양식 대신 "인터뷰 회고" 흐름에 맞춘 3칸 양식이 나오도록 합니다.

입력칸 순서
1. 가설과 일치했던 내용
2. 가설과 불일치했던 내용
3. 새로 알게 된 내용

세 칸 모두 여러 줄로 길게 쓸 수 있고(칸당 최대 8,000자, 글자수 표시), 각 칸에는 회색 예시 문구를 넣습니다. 예시 문구는 저장되지 않습니다.

## 동작 방식
- [인터뷰 기록] 탭과 동일한 방식이라 저장·수정·삭제, README 출력, 사례집 PDF 출력에 그대로 반영됩니다.
- 다른 탭(22일 팀빌딩·문제 정의 회의, 인터뷰 기록, 그 밖의 문제 정의 메모)은 지금과 똑같이 유지됩니다.
- 이미 이 탭으로 저장해 둔 내용이 있다면 열 위치가 같으므로 값은 그대로 보존됩니다.
- 새 줄 추가 버튼은 기존대로 [+ 그 밖의 문제 정의 메모 추가] 하나만 둡니다(추가 후 탭을 이 탭으로 바꿔 쓰면 됩니다).

## 기술 메모
- `src/lib/record-schema.ts`의 `PROCESS_SUBTYPE_TEMPLATES`에 `"인터뷰 후 문제 구체화 회의"` 항목 추가: `cols: ["가설과 일치했던 내용", "가설과 불일치했던 내용", "새로 알게 된 내용", "", "", ""]`, `longCols: [0,1,2]`, `fileCols: []`, `imageCols: []`, 예시 placeholders 포함.
- 렌더링/출력은 기존 `rowTemplate()` 경로를 그대로 타므로 에디터·README·사례집 코드 변경 없음.
- `src/routes/_main.guide.tsx`의 02 단계 설명에 이 탭 양식 안내 한 문장 추가.

# 공지 버튼화 + 에디터 링크/이미지 개선

## 1. 공지사항을 클릭 가능한 버튼으로

현재 게시판 목록의 공지사항(`src/routes/_main.board.$categoryId.index.tsx`)은 일반 `div`라 클릭해도 아무 일이 일어나지 않습니다. 질문게시판 항목처럼 `Link`로 바꿔 클릭 시 게시글 상세 페이지(`/board/$categoryId/$postId`)로 이동하게 합니다. 호버 애니메이션도 질문 카드와 동일하게 적용합니다. 상세 페이지는 이미 공지(`notice`) 타입 본문 렌더링을 지원하므로 추가 작업이 없습니다.

## 2. 본문 에디터 — 링크 삽입 모달

지금은 링크 버튼을 누르면 본문에 `[](https://)` 같은 마크다운 기호가 그대로 들어가 사용자가 "알 수 없는 부호"로 느낍니다. 첫 번째 스크린샷처럼 동작하도록 변경합니다.

- `src/components/PostEditor.tsx`의 링크 버튼을 누르면 **링크 삽입 모달**이 열립니다.
  - 입력 필드: **링크 제목**, **URL**
  - 안내문: "본문에는 URL이 노출되지 않고 \"링크 제목\" 카드로 표시됩니다."
  - "추가"를 누르면 커서 위치에 `[링크 제목](URL)` 마크다운을 삽입.
- 상세 페이지는 이미 `react-markdown`으로 렌더링하므로 링크가 제목 텍스트의 클릭 가능한 링크로 표시됩니다.

## 3. 본문 에디터 — 기기 사진 업로드

이미지 버튼도 현재 `![]()` 기호만 삽입됩니다. 기기에 저장된 사진을 불러와 업로드하도록 변경합니다.

- 이미지 버튼 클릭 → 숨겨진 `<input type="file" accept="image/*">` 트리거 → 파일 선택.
- 선택한 이미지를 Lovable Cloud 스토리지에 업로드하고, 반환된 공개 URL로 `![](URL)` 마크다운을 본문에 삽입.
- 업로드 중에는 토스트/로딩 표시, 실패 시 에러 토스트.

### 스토리지 준비 (마이그레이션)

현재 스토리지 버킷이 없으므로 공개 읽기 가능한 `post-images` 버킷을 생성합니다.

```text
- post-images 버킷 (public read)
- 업로드(insert) 정책: 익명/인증 사용자 허용 (게시글 작성이 비밀번호 기반이라 인증 불필요)
- 파일 크기/타입 제한 (이미지, 5MB 등)
```

업로드는 클라이언트에서 `supabase.storage.from("post-images").upload(...)` 후 `getPublicUrl`로 처리합니다.

## 적용 범위

- 변경 파일: `src/components/PostEditor.tsx`(링크 모달 + 이미지 업로드), `src/routes/_main.board.$categoryId.index.tsx`(공지 Link 화), 신규 스토리지 마이그레이션.
- `PostEditor`는 질문게시판·관리자 공지 작성·게시글 수정에서 공통으로 쓰이므로 세 곳 모두 동일하게 개선됩니다.

## 기술 세부

- 링크/이미지 삽입은 기존 `applyTool`의 selection 처리 로직을 재사용해 커서 위치에 삽입.
- 이미지 파일명은 충돌 방지를 위해 `crypto.randomUUID()` 등으로 생성.

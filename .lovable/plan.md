## 목표
달력 그리드 셀을 모바일에서 보기 좋게 최적화합니다. 좁은 화면에서 패딩/간격/폰트를 줄이고, "오늘" 강조가 세로로 길쭉한 캡슐로 보이는 문제를 정리합니다.

## 변경 대상
- `src/routes/_main.calendar.tsx` (달력 그리드 영역, 115~184행)

## 변경 내용
1. 컨테이너 패딩: `p-6` → `p-2 sm:p-6`, 그리드 간격 `gap-2` → `gap-1 sm:gap-2`
2. 요일 헤더: `text-sm` → `text-xs sm:text-sm`, 패딩 축소
3. 날짜 셀
   - 셀 패딩 `p-2` → `p-1 sm:p-2`
   - "오늘" 강조: 셀 전체 `bg-accent`로 인한 세로 캡슐 현상 제거 → 날짜 숫자 원형 강조만 유지하고 셀 배경은 은은하게(`bg-accent/40` 등)로 조정하거나 라운드 유지하면서 자연스럽게
   - 날짜 숫자: `h-8 min-w-8` → `h-6 w-6 text-xs sm:h-8 sm:min-w-8 sm:text-sm`
4. 공휴일/이벤트 텍스트: `text-xs`/`text-sm` → 모바일에서 더 작게(`text-[10px] sm:text-xs` 등), 이벤트 버튼 패딩 축소
5. 이벤트 표시가 좁은 셀에서 넘치지 않도록 truncate 유지 확인

## 검증
- 모바일 뷰포트(약 384px)에서 7열 셀이 균형 있게 들어가고 "오늘"·공휴일·이벤트 표시가 깔끔한지 확인
- 데스크톱에서 기존 레이아웃 유지 확인

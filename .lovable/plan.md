## 목표
상단 탭 메뉴 "홈" **왼쪽**에 "사용자 가이드" 메뉴를 추가하고, 사이트 사용법 전반을 설명하는 안내 페이지를 만든다. 이후 기능 변경 시 가이드가 항상 함께 갱신되도록 운영 규칙을 고정한다.

## 새 라우트: `src/routes/_main.guide.tsx`
- 경로 `/guide`, `createFileRoute("/_main/guide")`.
- `head()`에 고유 title/description/og 메타 설정 (SEO 대응).
- 한 페이지 안에서 섹션별로 스크롤되는 구조 + 상단에 목차(앵커 링크).
- 디자인은 기존 디자인 토큰(Card, primary, muted-foreground 등) 사용, 아이콘은 lucide.

### 포함 섹션 (요청 항목 전부)
1. **닉네임과 비밀번호를 설정하는 이유** — 로그인 계정이 아닌 닉네임 기반 활동 연결, 사칭 방지.
2. **닉네임 비밀번호 찾기** — 내 페이지의 "복구 질문" 설정 → 분실 시 질문 답변으로 자가 재설정, 미설정 시 관리자 초기화 안내.
3. **글 수정/삭제 비밀번호 vs 닉네임 비밀번호 차이** — 글·댓글별 수정/삭제용 비밀번호와, 닉네임 소유권(활동 귀속)용 비밀번호의 역할 구분.
4. **레벨(LV) 제도** — 글 5점/댓글 1점 등 활동 점수와 레벨 산정, 다음 레벨까지 점수 안내.
5. **배지 제도** — 관리자가 부여하는 배지, 내 페이지·작성자 배지 표시.
6. **보안 안전성** — 비밀번호는 해시로만 저장(평문 미저장), 서버에서만 검증, 닉네임 변경 시에도 활동 보존.
7. **메뉴 설명** — 캘린더 / 해커톤 / 자료집 / Dev Ground / Hello, World 각각의 용도.
8. **검색 기능** — 제목 / 제목+내용 / 작성자 모드 설명.
9. **내 페이지에서 할 수 있는 것** — 로그인, 레벨·배지·통계 확인, 내 글/댓글/좋아요(받은·누른) 보기, 닉네임 변경, 복구 질문 설정.
10. **관리자 대시보드 접근** — 우측 상단 톱니바퀴(설정) 아이콘 → 관리자 비밀번호 필요 안내.

## 탭 메뉴 추가: `src/routes/_main.tsx`
- `guideTab = { to: "/guide", label: "사용자 가이드", icon: BookOpen/HelpCircle }` 추가 (홈과 아이콘 중복 피해 `HelpCircle` 사용, import 추가).
- 데스크톱 `<nav>`에서 홈 링크 **앞**에 가이드 링크 배치, 활성 상태(`pathname.startsWith("/guide")`) 처리.
- 모바일 Sheet 메뉴에서도 홈 위에 동일 항목 추가.

## "자동 반영" 처리 방식
코드가 스스로 문서를 재작성할 수는 없으므로:
- 가이드 페이지를 사이트 사용법의 **단일 기준 문서**로 운영.
- 프로젝트 메모리에 규칙 저장: "기능을 추가/수정/삭제할 때마다 `/guide` 페이지(`_main.guide.tsx`)의 해당 설명도 반드시 함께 업데이트한다." → 이후 모든 작업에서 가이드 동기화가 기본 동작이 됨.

- 목차 앵커 스크롤 동작 확인.

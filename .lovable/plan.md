# 성장형 활동기록 저장 문제 2건 수정

테스트 보고서의 두 문제를 코드에서 원인까지 확인했습니다. 둘 다 저장 쪽 문제이고, 화면 구성이나 다른 게시판에는 영향이 없습니다.

## 문제 ① 빠르게 이어 쓰면 방금 쓴 내용이 사라짐

**원인(확인됨)**
- 입력할 때마다 1초 뒤 저장 요청을 보내는데, **앞 요청이 끝나기 전에 다음 요청이 출발**합니다. 두 번째 요청은 아직 갱신되지 않은 "내가 아는 마지막 저장 시각"을 들고 가므로 서버가 남이 고친 것으로 판단해 거절합니다("다른 곳에서 먼저 수정했어요").
- 거절되면 그 요청에 담겨 있던 입력분은 **이미 대기열에서 비워진 뒤**라 어디에도 남지 않고, 곧바로 서버 내용을 다시 불러오지도 않아 화면만 멀쩡해 보입니다. 새로고침하면 그 부분이 비어 있습니다.

**수정 내용**
- 저장 요청을 **한 번에 하나씩만** 보내도록 순서를 세웁니다. 저장 중에 생긴 입력은 대기했다가 앞 저장이 끝난 뒤 최신 시각으로 이어서 보냅니다. → 혼자 쓰는 동안에는 충돌 메시지가 나올 일이 없어집니다.
- 그래도 충돌이 나면(정말 다른 창에서 고친 경우) **실패한 입력분을 버리지 않고 대기열로 되돌린 뒤**, 최신 저장 시각을 받아 자동으로 한 번 다시 저장합니다.
- 저장 실패 시 화면 값을 서버 내용으로 되돌리지 않습니다. 상단 표시를 `자동 저장됨` / `저장 중...` 외에 **`아직 저장되지 않았어요`(주황색)** 를 추가해 눈에 띄게 보여 주고, 저장되지 않은 상태로 페이지를 벗어나려 하면 브라우저 확인창을 띄웁니다.
- 단계 이동·제출 등에서 쓰는 즉시 저장(flush)도 같은 순서 규칙을 따르게 합니다.

## 문제 ② 작성률이 100%가 되지 않음

**원인(확인됨)**
- `개인정보 처리 여부`(privacy)는 화면에도 있고 DB 컬럼도 있는데, **서버가 받는 항목 목록에만 빠져 있습니다.** 그래서 저장 요청에 담겨도 조용히 버려지고, 새로고침하면 선택이 풀립니다. 05가 5/6에서 멈추고 전체 90%에서 더 오르지 않습니다.

**수정 내용**
- 서버 저장 항목에 `privacy`를 추가합니다(선택지 3개 중 하나만 허용). 이후 선택이 정상 저장되고 진행률 100%가 가능해집니다.
- 이미 화면에서 선택했다가 저장되지 않은 기존 기록은 한 번 다시 눌러 주면 저장됩니다(과거 데이터 복구는 불가능합니다).

## 기술 메모

- `src/lib/record-growth.functions.ts`
  - `saveGrowthRecord` 입력 스키마 `patch`에 `privacy: z.enum([...GROWTH_PRIVACY_OPTIONS, ""]).optional()` 추가. (근본 원인: `privacy`가 `GROWTH_ALL_FIELDS`에 없어 `textPatchShape`에서 제외됨. 필드 목록 자체는 화면 렌더 순서와 얽혀 있으므로 건드리지 않고 패치 스키마에만 명시 추가.)
  - 낙관적 잠금 로직과 `review` 병합 방식은 그대로 둡니다.
- `src/components/record/GrowthRecordEditor.tsx`
  - `flush`에 in-flight 잠금(`saving` ref + 이어달리기 큐) 도입, 실패 시 `pending.current = { ...patch, ...pending.current }`로 되돌림.
  - 충돌 메시지 감지 시 `getGrowthRecord`를 한 번 다시 읽어 `knownUpdatedAt`만 갱신하고 재시도(재시도 1회). 실패해도 `setData`는 하지 않음.
  - 실패 경로에서 `queryClient.invalidateQueries` 즉시 호출 제거(입력값 되돌림 원인).
  - 상태 표시에 `unsaved` 추가, `beforeunload` 경고.
- DB 마이그레이션 없음. 도전형 기록·나눔·투표·`/guide`는 변경하지 않습니다.

## 확인 방법

- 04 자기 점검 6개를 쉬지 않고 연속 클릭 → 새로고침 후 6개 모두 유지되는지
- 04 수정 기록 3칸 연속 입력 → 새로고침 후 유지되는지
- 05 개인정보 처리 여부 선택 → 새로고침 후 유지, 진행률 100% 도달

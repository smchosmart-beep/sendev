## 목표
모바일에서 어수선하게 줄바꿈되는 상단 헤더를, 햄버거 메뉴 방식으로 정리합니다. 데스크톱(sm 이상)은 현재 가로 탭 레이아웃을 그대로 유지합니다.

## 변경 대상
- `src/routes/_main.tsx` (헤더 부분만 수정)

## 동작
```text
[모바일 < sm]
┌────────────────────────────┐
│ 로고  교사개발자플랫폼   [☰] │   ← 한 줄, 깔끔
└────────────────────────────┘
   ☰ 탭 → 우측 Sheet(드로어) 슬라이드:
     · 캘린더
     · 해커톤 / 자료집 / Dev Ground / Hello, World
     · 관리자(설정)
   항목 선택 시 드로어 자동 닫힘, 현재 위치 강조

[데스크톱 ≥ sm]
   기존 가로 탭 + 우측 설정 아이콘 그대로 유지
```

## 구현 세부
- 기존 `nav`(가로 탭)와 우측 설정 아이콘을 `hidden sm:flex`로 감싸 데스크톱 전용으로 둠.
- 모바일 전용으로 우측에 햄버거 버튼(`Menu` 아이콘, `sm:hidden`) 추가.
- shadcn `Sheet` 컴포넌트(`@/components/ui/sheet`)로 우측 드로어 구성. 없으면 추가 설치.
- 탭 목록(`calendarTab` + `boardTabs`)과 관리자 링크를 드로어 안에 세로 리스트로 렌더, 기존 활성 상태 로직(`isCalendar`, `activeGroup`) 재사용.
- 드로어 열림 상태는 `useState`로 관리, 링크 클릭 시 닫기.
- 로고 텍스트("교사 개발자 플랫폼")는 모바일에서도 보이도록 조정(공간 확보됨).

## 검증
- 모바일 뷰포트(약 384px)에서 한 줄 헤더 + 햄버거 동작, 드로어 열림/닫힘/활성 강조 확인.
- 데스크톱 뷰에서 기존 레이아웃 변화 없는지 확인.

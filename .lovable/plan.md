# 사례집 팀원 표시 형식 개선

사례집 PDF(표지 + 07 제작자와 라이선스)에서 팀원 정보를 더 읽기 쉽게 표시합니다.

## 변경 내용

1. **표지 팀원 정보**
   - 현재: `이름 · 소속 · 역할, 이름 · 소속 · 역할, ...` 형태로 한 줄 연결
   - 변경: 각 팀원을 별도 줄(블록)로 분리
   - 팀원 이름은 더 큰 글씨(예: 14pt)로 강조
   - 소속·역할은 이름 아래 작은 글씨(예: 9.5pt)로 표시

2. **07 제작자와 라이선스 팀원 목록**
   - 현재: `ul > li`에 `이름 · 소속 · 역할`을 한 줄로 표시
   - 변경: 각 `li`를 이름/소속·역할 두 줄 구조로 분리
   - 이름은 더 큰 글씨, 소속·역할은 보조 색상으로 축소 표시

3. **스타일**
   - `src/styles.css`의 사례집 스타일 영역에 `.casebook-member`, `.casebook-member-name`, `.casebook-member-meta` 클래스 추가
   - 인쇄(`@media print`) 스타일에서도 동일하게 적용

## 수정 파일

- `src/styles.css`

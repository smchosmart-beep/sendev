# 투표 게시판 글 본문이 보이지 않는 문제 수정

등록 시 내용은 정상적으로 저장되지만, 게시글 상세 화면이 본문을 **일반글(type = post)일 때만** 그리도록 되어 있어 투표 글은 제목만 보입니다. 수정 창에서도 투표 글은 본문 입력칸이 없고, 저장 시 내용 항목이 함께 전송되지 않아 본문이 사라질 수 있습니다.

## 수정 내용

1. **상세 화면 본문 표시**: 투표 글도 본문 영역(마크다운 렌더링, 링크 미리보기 포함)을 일반글과 동일하게 표시합니다.
2. **수정 창**: 투표 글 수정 시 "내용" 편집기와 "작성자" 입력을 제공하고, 저장할 때 제목·내용·작성자·대표 링크가 함께 전송되도록 합니다.
3. **대표 링크**: 투표 글은 썸네일에 쓰이는 대표 링크(배포 URL)도 수정 창에서 함께 바꿀 수 있게 합니다.

## 기술 메모

- `src/routes/_main.board.$slug.$postNo.tsx`
  - 본문 렌더링 조건 `isBoardPost` → `isBoardPost || post.type === "vote"` (402행 블록).
  - 수정 폼 분기(1584행)와 `editMutation` 페이로드(1213행)에 투표 타입 분기 추가: `{ id, password, title, content, author, deployUrl }`.
  - `noun` 계산에 투표 게시판 이름(`category.voteName`) 반영.
- 서버 함수(`updatePost`)는 이미 content/author/deployUrl을 선택적으로 받으므로 DB·서버 변경은 없습니다.

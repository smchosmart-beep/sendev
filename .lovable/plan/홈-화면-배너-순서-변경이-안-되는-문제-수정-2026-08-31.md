# 홈 화면 배너 순서 변경이 안 되는 문제 수정

## 원인

관리자 대시보드 "홈 화면 구성"의 위/아래 이동 버튼이 서버로 **관리자 비밀번호를 함께 보내지 않습니다.**
서버의 순서 변경 함수는 관리자 확인을 먼저 하기 때문에, 요청이 항상 거부되어 순서가 바뀌지 않고
"순서 변경 중 문제가 발생했어요." 안내만 뜨는 상태입니다.

(업로드·삭제 버튼은 비밀번호를 함께 보내고 있어 정상 동작합니다. 배너 데이터의 순서 값 자체는 0~4로 정상입니다.)

## 수정 내용

- `src/routes/admin.home.tsx`의 순서 변경 요청에 관리자 비밀번호를 포함시킵니다(삭제 버튼과 동일한 방식).
- 순서 변경 후 목록이 즉시 갱신되도록 기존 무효화 처리를 그대로 사용합니다.

## 기술 세부

`swapMutation`의 `mutationFn`에서
`swapFn({ data: { ...vars, adminPassword: getAdminPassword() } })` 형태로 호출하도록 변경.
서버 함수(`swapHeroSlideOrder`)는 이미 올바르게 두 슬라이드의 `sort_order`를 맞바꾸므로 변경하지 않습니다.

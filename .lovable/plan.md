# 출력 보기 09번 블록 "작성됨" 오표시 수정

## 문제
새 활동기록 글을 등록하면 아무 내용을 쓰지 않아도 출력 보기의
`09 제작자와 라이선스`가 곧바로 "작성됨"으로 표시됩니다.

원인: 09번 블록의 판정 조건이 팀원 목록이 하나라도 있으면 작성된 것으로 보도록
되어 있는데, 글을 만들면 작성자가 자동으로 팀원에 등록되기 때문입니다.

## 수정 방향
09번 블록은 사용자가 실제로 입력한 내용이 있을 때만 "작성됨"으로 표시합니다.

- 제작자와 담당(maker) 행이 있거나
- 코드/문서 라이선스, 외부 자료 출처 중 하나라도 채워졌거나
- 팀원 항목에 이름 외에 소속 또는 역할이 입력된 경우

위 중 어느 것도 없으면 "미작성"으로 남습니다.

## 기술 세부
- `src/lib/record-readme.ts`의 `getPublicReadmeBlocks` 내 9번 블록 `filled` 조건에서
  `team.members.length > 0`을 제거하고, 소속/역할이 채워진 팀원이 있는지 검사하는
  조건으로 교체합니다.
- README 본문 생성 로직(`buildPublicReadme`)은 그대로 두어 기존 출력에는 영향이 없습니다.
- 다른 블록(01~08) 판정과 저장 로직은 변경하지 않습니다.

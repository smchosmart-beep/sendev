# README 양식 개선 — 설치/실행 대신 "배포 주소 + 사용법"

현재 README 생성기는 `⚙️ 설치 및 실행 (Getting Started)` 섹션에 npm/yarn/pnpm 설치·빌드 명령을 그대로 찍어 넣습니다. 프로젝트마다 거의 동일한 뻔한 내용이라 실제 도움이 되지 않습니다. 이 섹션을 없애고, 직접 작성하는 실용적인 두 섹션으로 바꿉니다.

## 바뀌는 내용

기존:
- GitHub 저장소 주소 / 폴더명 입력 → 클론·설치·실행·빌드 명령 자동 생성

변경 후:
- **🔗 배포 주소 (Live Demo)**: 배포된 서비스 주소 입력 (비우면 섹션 생략)
- **📖 사용법 (How to Use)**: 자유 입력(여러 줄). 단계별로 쓰면 번호 목록처럼 그대로 반영 (비우면 섹션 생략)
- GitHub 저장소 주소는 유지하되, 명령어 블록 없이 배포 주소 섹션 안에 "GitHub 저장소" 링크 한 줄로만 표시

## 화면

입력 폼의 "설치 및 실행" 카드가 "배포 주소 및 사용법" 카드로 바뀝니다.
- 배포 주소 (입력창)
- GitHub 저장소 주소 (입력창, 선택)
- 사용법 (여러 줄 입력창, 안내 문구: "접속 후 무엇을 어떻게 하면 되는지 단계별로 적어보세요")

나머지(기본 정보 / 주요 기능 / 기술 스택 / 추가 설명, 미리보기, 다운로드·복사·초기화)는 그대로입니다.

## 주의 사항

- 이미 브라우저에 저장된 기존 입력값(localStorage)이 있어도 오류 없이 열리도록, 새 항목은 기본값으로 채워 병합합니다. 기존 `folderName` 값은 더 이상 쓰이지 않고 무시됩니다.
- 배포 주소와 GitHub 주소는 링크로 삽입되므로 마크다운 링크 구문이 깨지지 않게 처리합니다.

## 기술 메모

- `src/lib/readme-template.ts`: `ReadmeData`에서 `folderName` 제거, `liveUrl`·`usage` 추가. `generateReadme`의 설치/실행 블록을 배포 주소 섹션 + 사용법 섹션으로 교체(각각 값이 있을 때만 출력).
- `src/routes/_main.readme.tsx`: 해당 입력 카드 교체(Input 2개 + Textarea 1개).
- `src/routes/_main.guide.tsx`: README 작성 안내 문구를 새 항목에 맞게 수정.

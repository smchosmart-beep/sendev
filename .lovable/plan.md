# 투표 게시판 글 등록 템플릿 자동 채움

투표 게시판에 후보 글을 등록할 때 본문 편집기에 미리 정해진 템플릿이 자동으로 들어가 있도록 하고, 사용자 가이드에도 이 사실을 명시합니다.

## 수정 내용

1. **투표 글 등록 폼 본문 기본값 변경**
   - `src/routes/_main.board.$slug.new-vote.tsx`의 `content` 상태 초기값을 다음 템플릿 문자열로 설정합니다.
   ```
   [누구] 은/는

   [어떤 상황] 에서

   [근본 원인] (으)로 인해

   [구체적 고통(QQQ)] 와/과 같은 어려움을 겪고 있을 것이다.
   ```
   - 사용자가 원하면 직접 수정하거나 지울 수 있습니다.

2. **사용자 가이드 업데이트**
   - `src/routes/_main.guide.tsx`의 투표 게시판 설명에 "글 등록 화면의 본문에는 위 템플릿이 자동으로 채워져 있어, 작성자가 안내에 맞춰 내용을 바꿔 넣을 수 있습니다"라는 문구를 추가합니다.

## 부작용 검토

- 기존 일반글·산출물·링크·문제ZIP 등록 폼에는 영향을 주지 않습니다.
- 본문 필드는 서버에서 선택적으로 저장되므로 추가 DB 변경이 없습니다.
- 템플릿을 지우고 빈 본문으로 등록하는 것도 여전히 가능합니다(강제가 아님).

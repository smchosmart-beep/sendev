# 유튜브 링크 재생 버튼 추가

## 목표
활동기록 에디터의 "종이 프로토타입 유튜브 영상 링크" 입력란에 URL을 입력하면, 링크 텍스트 오른쪽에 재생 버튼(Play 아이콘)을 표시하고 클릭 시 새 탭에서 영상을 열게 한다.

## 변경 범위
- `src/components/RecordEditor.tsx`
  - `RowItem` 컴포넌트의 링크 표시 영역(1400-1420 라인) 수정.
  - 입력값이 있을 때 기존 "링크 열기 · URL" 텍스트 링크 옆에 `Play` 아이콘 버튼 추가.
  - 버튼 클릭 시 `normalizeUrl()`로 보정된 주소를 새 탭에서 열도록 처리.
  - 유튜브 링크인 경우에만 재생 버튼을 노출하고, 다른 링크는 기존 텍스트 링크로 유지.
- `src/routes/_main.guide.tsx`
  - 활동기록 02 문제 정의 과정 안내에 "유튜브 영상 링크 입력 시 재생 버튼으로 바로 확인" 내용 추가/갱신.

## 기술 상세
- `lucide-react`의 `Play` 아이콘 사용.
- 유튜브 도메인 판정: `youtu.be`, `youtube.com`, `m.youtube.com` 등 호스트명으로 확인.
- 버튼은 `aria-label="영상 재생"` 등 접근성 속성 포함.
- 기존 URL 자동 프로토콜 보정(`normalizeUrl`) 로직은 그대로 유지.
- 새로운 기능 추가만 있으며 기존 저장/검증 로직, DB 스키마, RLS 등에는 영향 없음.

## 검증
- 타입 체크 통과 확인.
- 미리보기에서 유튜브 URL 입력 후 재생 버튼이 표시되고 클릭 시 새 탭 열리는지 확인.
- 유튜브가 아닌 일반 URL 입력 시 기존 "링크 열기" 텍스트가 그대로 표시되는지 확인.

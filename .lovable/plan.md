# 투표 게시판 게시글 카드 크기 확대

투표 게시판의 후보 글 카드가 현재 너무 작게 보여 가독성이 떨어집니다. 한 줄에 노출되는 개수를 줄이고 카드 내부 여백/글자 크기를 키우는 방향으로 조정합니다.

## 현재 상태

- 파일: `src/components/VoteSection.tsx`
- 한 줄 노출 개수: **모바일 2개 / sm 3개 / lg 6개**
- 한 페이지: 36개(`PAGE_SIZE = 36`), 페이지네이션 유지
- 카드: `p-3`, 제목 `text-sm`, 작성자 `text-xs`, 투표 버튼 `h-7 text-xs`

## 수정 내용

1. **그리드 컬럼 수 조정**  
   `grid-cols-2 gap-3 sm:grid-cols-3 lg:grid-cols-6` → `grid-cols-2 gap-3 sm:grid-cols-4`  
   → 모바일 2개, 그 외 화면(태블릿/중간 화면/데스크탑) 모두 4개로 줄여 카드 폭을 넓힙니다.

2. **제목 가독성을 최우선으로 확대**  
   - 제목: `text-sm` → `text-base`, `line-clamp-2` → `line-clamp-3`  
   - 패딩: `p-3` → `p-4`  
   - 작성자: `text-xs` → `text-sm`  
   - 투표 버튼: `h-7 px-2 text-xs` → `h-8 px-3 text-sm`  
   - 등수 뱃지/비공개 문구 크기도 약간 키움

3. **페이지 크기 및 페이지네이션 유지**  
   `PAGE_SIZE = 36`은 그대로 두어 한 페이지에 36개 후보가 계속 노출되고, 크기가 커진 만큼 세로 스크롤이 늘어나는 것은 감수합니다.

## 부작용 검토

- **다른 게시판 영향 없음**: 변경은 `VoteSection` 컴포넌트 내부 그리드 스타일만 해당합니다.
- **데이터/DB 변경 없음**: 프레젠테이션 레이어 수정입니다.
- **모바일 고려**: 모바일은 2개 유지, 글자 크기 확대로 제목 말줄임이 더 길어질 수 있으나 `line-clamp-2`로 제한합니다.
- **관리자 종료 후 유권자 목록**: 기존에 한 줄로 노출되던 투표자 이름은 카드가 커지면 가독성이 향상됩니다(기능 변화 없음).

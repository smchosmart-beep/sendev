# 모바일 평가 입력: 별점 → 숫자 입력 방식

모바일 화면에서 산출물 평가의 별점(10개 별)이 화면을 넘쳐 잘리는 문제를 해결합니다. PC는 지금처럼 별점을 유지하고, 모바일에서만 점수 입력 UI로 바꿉니다.

## 동작

- **PC(768px 이상)**: 지금과 동일한 별점(드래그/클릭, 0.5점 단위) 유지.
- **모바일(768px 미만)**: 각 평가 항목이 아래 형태로 표시됩니다.

```text
기획력 (0.5점 단위 · 만점 20)
[ − ]   7.0 / 20   [ ＋ ]
```

- 가운데 숫자는 **직접 탭해서 입력**도 가능(숫자 키패드가 뜸). 0~만점 사이, 0.5점 단위만 허용되며 범위를 벗어나면 자동으로 보정됩니다.
- −/＋ 버튼은 0.5점씩 감소/증가.
- 현재 점수 표시(`7.0 / 20`)는 지금과 동일하게 유지.

## 기술 세부

- `src/routes/_main.board.$slug.$postNo.tsx`
  - 기존 `useIsMobile` 훅(`src/hooks/use-mobile.tsx`, 768px 기준)을 평가 섹션에서 사용.
  - `StarRating` 사용부(:2163)를 분기: 모바일이면 새 `ScoreStepper` 컴포넌트(같은 파일 내에 추가, −/＋ 버튼 + `<input inputMode="decimal">`), 아니면 기존 `StarRating`.
  - `ScoreStepper`는 `max`/`value`/`onChange` props로 `StarRating`과 동일한 계약 — 폼 상태·제출 로직은 전혀 손대지 않음.
  - 입력 보정: `Math.round(v * 2) / 2` 후 0~max로 클램프. blur 시 확정.
- 점수 값 체계(0.5 단위, 0~20)와 저장 경로는 그대로이므로 서버·DB 변경 없음.
- 평가 요약(잠금 표시) 등 다른 화면에는 영향 없음.

## 부작용 검토

- `StarRating`은 평가 섹션에서만 쓰이며, PC 동작은 코드 변경이 없어 회귀 없음.
- 모바일/PC 경계(768px)에서 창 크기를 바꾸면 입력 위젯이 교체되지만 점수 값은 상위 state에 있어 유지됨.
- 활동기록 윤리 설문의 별점(`EthicsSection`)은 별 5개라 잘리지 않으므로 이번 변경 대상에서 제외.

## 마무리

- 사용자 가이드(`/guide`)의 평가 안내에 "모바일에서는 −/＋ 버튼과 숫자 입력으로 점수를 매겨요" 한 줄 추가.

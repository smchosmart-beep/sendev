## 목표

유튜브·캔바처럼 **썸네일(미리보기)이 크게 보이는 링크 공유 게시판 유형**을 추가합니다. 산출물 게시판과 비슷하지만 더 단순하게 **제목 / 작성자 / 비밀번호 / 링크**만 입력하고, 링크의 미리보기 썸네일이 카드에 잘 보이도록 합니다.

## 동작 방식

- 관리자가 게시판 설정에서 **"링크 게시판"** 종류를 켜고 이름(예: "추천 영상", "디자인 모음")을 지정할 수 있습니다.
- 사용자는 해당 게시판에서 제목·작성자·링크·비밀번호만 입력해 글을 등록합니다.
- 등록 시 링크 주소의 미리보기 이미지(OG 이미지)를 자동으로 가져와 카드 썸네일로 크게 표시합니다. (이미 산출물 게시판에서 쓰는 미리보기 추출 기능을 그대로 재사용)
- 카드 그리드 형태로 보여 유튜브/캔바처럼 한눈에 썸네일을 훑을 수 있습니다.

## 작업 내용

### 1. 데이터베이스 (마이그레이션)
`categories` 테이블에 두 컬럼 추가:
- `enable_link` (boolean, 기본 false — 기존 게시판에는 영향 없음)
- `link_name` (text, 기본 '링크')

게시글은 기존 `posts` 테이블을 그대로 사용하고, 새 글 종류 `type = 'link'`를 사용합니다. 링크 주소는 기존 `deploy_url` 컬럼에 저장해 미리보기 썸네일 추출 파이프라인(og_image_url 캐싱)을 그대로 활용합니다.

### 2. 서버 로직 (`src/lib/platform.functions.ts`)
- `CategoryDTO`에 `enableLink`, `linkName` 추가 + 조회/생성/수정 스키마와 매핑 반영
- `createPost`/`updatePost`의 글 종류에 `"link"` 추가 (링크 게시판은 GitHub 필수 검증 없음, 링크 주소로 미리보기 이미지 자동 추출·캐싱)
- `PostDTO` 타입에 `"link"` 추가

### 3. 관리자 게시판 설정 (`src/routes/admin.categories.tsx`)
- 추가/수정 폼의 "사용할 게시판 종류"에 **링크 게시판** 토글 추가
- 토글을 켜면 **링크 게시판 이름** 입력칸 표시 (산출물 이름 입력과 동일한 패턴)

### 4. 글 등록 화면 (신규 `src/routes/_main.board.$slug.new-link.tsx`)
- 입력 필드: 제목, 작성자, 링크 URL, 비밀번호 (산출물 폼보다 단순)
- 링크 형식 검증 후 등록

### 5. 게시판 목록 (`src/routes/_main.board.$slug.index.tsx`)
- `enableLink`가 켜진 게시판에 **링크 섹션** 추가
- 썸네일을 강조한 카드 그리드로 표시 (썸네일 영역을 산출물 카드보다 크게, 16:9 비율로)
- 등록 버튼은 새 등록 화면으로 연결

### 6. 글 상세 화면 (`src/routes/_main.board.$slug.$postNo.tsx`)
- `type === 'link'` 처리: 링크 바로가기 버튼, 미리보기 표시, 작성자 표시
- 비밀번호로 수정·삭제 (명칭은 게시판의 링크 이름 사용)

## 기대 결과

관리자가 링크 게시판을 켜면, 사용자는 제목·작성자·링크·비밀번호만으로 글을 올릴 수 있고, 링크의 썸네일이 카드에 크게 표시되는 유튜브/캔바 스타일의 링크 모음 게시판이 만들어집니다.

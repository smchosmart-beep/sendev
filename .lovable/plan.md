# 카드 작성자 이름 줄바꿈 방지

이전 조치(마우스 오버 시 전체 이름 표시)는 표시만 보완했을 뿐, 실제로 "김승 / 현"처럼 이름이 두 줄로 쪼개지는 현상은 그대로입니다. 이번에는 레이아웃 자체를 고칩니다.

## 원인

작성자 영역이 `이름 + 레벨/역할 배지`를 한 줄 flex로 묶어 두었는데, 카드 폭이 좁으면 배지가 공간을 차지하면서 이름 텍스트가 글자 단위로 줄바꿈됩니다.

## 변경 내용

`src/routes/_main.board.$slug.index.tsx`의 카드 작성자 영역(링크 카드, 프로젝트 카드, 공지/일반/문제ZIP 카드)에 동일한 규칙을 적용합니다.

- 작성자 이름은 항상 한 줄 유지, 넘치면 말줄임(...) 처리 (`whitespace-nowrap truncate`, 부모에 `min-w-0`)
- 아이콘과 레벨/역할 배지는 줄어들지 않도록 `shrink-0`
- 이름과 배지가 한 줄에 다 안 들어가면 이름은 잘리고 배지는 그대로 표시
- 기존 `title` 속성은 유지해 전체 닉네임을 마우스 오버로 확인 가능

## 범위 밖

데이터·쿼리·권한 로직은 변경하지 않으며, 순수 CSS 클래스 수준의 표시 조정만 합니다.

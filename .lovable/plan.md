# 유튜브 링크 입력 영역 개선

## 목표
활동기록 02 문제 정의 과정의 '22일 팀빌딩·문제 정의 회의' 탭에서, 유튜브 링크 입력 시 "링크 열기" 텍스트와 재생 버튼이 중복되어 나오지 않도록 정리하고, 입력창을 짧게 줄인 뒤 줄어든 공간에 재생 버튼을 배치한다.

## 변경 범위

### `src/components/RecordEditor.tsx`
- `RowItem` 컴포넌트의 링크 입력 영역(약 1492-1526 라인)을 수정한다.
- 입력칸과 버튼을 한 줄(`flex`)로 배치한다.
- 입력창은 `max-w-md` 등으로 너비를 제한해 현재처럼 길게 늘어지지 않게 한다.
- 값이 유튜브 URL이면:
  - "링크 열기 · URL" 텍스트 링크는 제거한다.
  - 재생 버튼(`Play` 아이콘)을 입력창 오른쪽에 배치하고, 클릭 시 보정된 URL을 새 탭에서 연다.
- 값이 유튜브가 아닌 일반 링크이면:
  - 기존 "링크 열기" 텍스트 링크를 그대로 유지한다.
- 재생 버튼은 `aria-label="영상 재생"`을 유지하고, 시각적으로는 원형 배경 안에 `Play` 아이콘으로 표시한다.

### `src/routes/_main.guide.tsx`
- 활동기록 02 문제 정의 과정 안내 문구에서, 유튜브 링크 입력 시 입력창 옆의 재생 버튼으로 바로 영상을 볼 수 있다는 점을 반영한다.

## 기술 상세
- 기존 `isYouTubeUrl()`과 `normalizeUrl()` 유틸리티를 재사용한다.
- 입력창 길이 제한은 `max-w-md` 또는 동등한 너비 제한 유틸리티를 사용한다.
- 레이아웃은 flex gap을 이용해 입력창과 버튼이 한 줄에 자연스럽게 맞물리게 한다.
- 저장/검증 로직, DB 스키마, RLS, 파일 업로드에는 영향을 주지 않는다.

## 검증
- 타입 체크 통과 확인.
- 미리보기에서 유튜브 URL 입력 시: 텍스트 링크 없이 입력창 오른쪽에 재생 버튼만 표시되는지 확인.
- 유튜브가 아닌 URL 입력 시: 기존 "링크 열기" 텍스트 링크가 정상 표시되는지 확인.
- 재생 버튼 클릭 시 새 탭에서 정상 재생되는지 확인.

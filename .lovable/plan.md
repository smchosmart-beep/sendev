## 문제ZIP 영역별 필터 버튼 추가

문제ZIP 목록 상단(정렬 토글 옆)에 Q1 영역 필터 버튼을 추가해 영역별로 게시글을 골라볼 수 있게 함.

### 버튼 구성
- `전체` + 관리자 설정의 영역 목록(현재 보건/건강, 행정/공문, 수업/평가, 학부모소통, 학교행사) = 총 6개
- 설정 목록에 없는 영역(직접 입력으로 등록된 값, 예: 기초학력지원)이 있으면 맨 뒤에 `직접 입력` 버튼을 표시 — 누르면 직접 입력으로 작성된 글(기초학력지원 등)이 모두 보임
- 각 버튼에 해당 영역 글 수를 함께 표시 (전체 대비 몇 건인지 바로 파악)

### 동작
- 선택한 영역은 URL 검색 파라미터 `parea`에 저장 → 새로고침/공유/뒤로가기에서 유지
- 영역을 바꾸면 페이지 번호(`ppage`)는 1로 리셋
- 정렬(최신순/좋아요순)과 독립적으로 조합 가능. 정렬을 먼저 적용하고 그 뒤에 영역 필터를 적용해 좋아요 배치 조회 키가 필터에 흔들리지 않게 함
- 필터 결과가 없으면 "해당 영역의 문제가 아직 없어요" 안내 표시

### 기술 세부
- `src/routes/_main.board.$slug.index.tsx`
  - `validateSearch`에 `parea: string` 추가(기본값 `""` = 전체). 검색 파라미터 타입이 여러 곳에 인라인으로 적혀 있으므로 공통 타입 별칭으로 정리
  - 라우트 loader에 `problemOptionsQueryOptions()` prefetch 추가 (영역 버튼 목록 소스, 이미 `staleTime` 5분 캐시라 추가 부하 없음)
  - 필터링은 이미 로드된 `posts` 배열에서 `post.problemArea` 비교로 클라이언트 처리 → 추가 DB/서버 호출 없음
  - 페이지네이션(`problemPageCount`, `pagedProblems`)은 필터 적용 후 배열 기준으로 계산
  - 좋아요순 전체 조회 키(`allProblemIds`)는 필터 이전 전체 problems 기준 유지
- `src/routes/_main.guide.tsx`: 문제ZIP 안내에 영역 필터 사용법 한 줄 추가

### 부작용 검토
- 서버 호출 증가 없음 (클라이언트 필터링, 기존 쿼리 키 유지)
- 다른 게시판 유형(일반/링크/산출물/질문)은 분기 밖이라 영향 없음
- SSR/하이드레이션: URL 파라미터 기반이라 서버·클라이언트 렌더 결과 동일
